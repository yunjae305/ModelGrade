# AIONA Q165 통합 데이터셋

기존 단건 Q100에 사용자가 제공한 멀티턴 Q/A 65개를 추가한 파일입니다. 질문과 답변은 모두 AIONA 서비스에서 받은 원문이며, 병합하면서 문자열을 수정하지 않았습니다.

- 서비스 기본 파일: `data/code_eval/AIONA_winz_Q165_Q100_multiturn65_v1.json`
- 기존 Q100 원본: `data/code_eval/AIONA_winz_set2_Q100_id_question_answer_v1.json`
- 제공받은 멀티턴 원본 보관: `data/code_eval/AIONA_winz_멀티턴_1-3회차_통합.json`

| 구분 | 항목 ID | 대화 ID | 턴 수 | 내용 |
|---|---|---|---:|---|
| 기존 단건 | Q001~Q100 | 없음 | 100개 독립 질문 | 기존 Q100 전체 |
| 1회차 | Q101~Q115 | AIONA_MT_01 | 15 | 체중 관리·식단·운동 |
| 2회차 | Q116~Q135 | AIONA_MT_02 | 20 | AI 웹 서비스 프로젝트 |
| 3회차 | Q136~Q165 | AIONA_MT_03 | 30 | 자취 준비와 생활 계획 |

각 멀티턴 항목에는 `conversation_id`, 원래 `turn`, 고유 `id`, `system_id: "aiona"`, 원본 파일명을 담은 `source`, 회차를 담은 `source_group`을 추가했습니다. 각 회차의 턴은 1부터 연속되며 회차 사이에는 대화 이력을 공유하지 않습니다. 기존 Q100 100개 객체는 그대로 유지했습니다.

워크스페이스의 **Q165 통합 파일로 둘러보기**로 불러오거나 통합 JSON을 직접 업로드합니다. 파일 정보에는 단건 100개·멀티턴 65개와 대화 3개가 표시됩니다. 전체 Q/A 보기에서 항목을 선택하면 회차와 턴 번호도 확인할 수 있습니다. 기존에 저장된 Q100 결과의 항목 수나 판정은 바뀌지 않습니다.

현재 업로더는 원본 `AIONA_winz_멀티턴_1-3회차_통합.json`의 회차별 묶음도 자동 변환합니다. 이 원본만 올리면 멀티턴 65개·대화 3개가 되며, 기존 단건 100개를 자동으로 덧붙이지는 않습니다. 전체 165개를 비교하려면 Q165 통합 파일을 사용합니다. MD·TXT 변환 규칙은 [서비스 안내](SERVICE_UI.md#jsonmdtxt-자동-변환)를 참고하세요.

## 롱컨텍스트 평가 범위

J6는 각 대화의 두 번째 턴부터 적용하므로 대상은 14 + 19 + 29 = **62개 턴**입니다. 마지막 턴은 각각 앞선 14·19·29개 턴을 참조합니다. 비교 모델의 응답 수집은 각 모델 자신의 이전 질문·답변 이력을 사용합니다.

의미 평가기 `jev-semantic-eval-v2.3`부터 **이전 질문·답변 전문을 원문 그대로 전달합니다.** 턴당 2,000자 축약, 전체 60,000자 제한, 오래된 답변을 300자로 줄이는 처리와 길이 초과 시 이력 생략을 제거했습니다. 공백·CRLF·코드 펜스·리터럴 `\\n`·마지막 문자까지 보존합니다. 새 의미 결과는 `history_policy: "full_original_text"`, `context.history_truncated: false`를 기록합니다.

통합 JSON, 현재 평가 대상 답변과 이전 대화 이력 모두 전문을 보존합니다. 제공자가 전체 요청을 거절하면 호출 오류로 기록하며, 이력을 줄여 다시 평가하거나 PASS로 대신 표시하지 않습니다. 실제 모델·의미 평가 서비스 호출은 하지 않았습니다.

## 검증

`python -m pytest -q tests/test_combined_aiona_dataset.py`로 원본 Q100의 보존, 추가 65개 질문·답변의 정확한 일치, 고유 ID, 회차별 연속 턴, 업로더 입력, 대화 간 이력 분리 및 J6 적용 62개를 확인합니다. 의미 평가는 명시적으로 연결 없는 테스트 경로를 사용합니다.

`python tests/workspace_ui_smoke.py`로 기본 Q165 불러오기, 질문 165개·대화 3개 표시, Q101의 1회차 1턴과 Q165의 3회차 30턴 탐색을 포함한 기존 서비스 흐름을 확인합니다.

`python -m pytest -q tests/test_full_history_original_text.py`로 Q165 165개 실제 HTTP 본문, 2,000자·60,000자를 넘는 Claude CLI 표준 입력의 JSON을 디코딩해 원문과 직접 비교합니다. HTTP와 CLI는 대역이며, 컨텍스트 거절 시 축약 요청 없이 호출 오류·대화 미완료로 남는 경로도 확인합니다.
