### 4-2. 근거 없는 FAIL과 재평가 (D-1)

- **근거 없는 FAIL 0건, 재평가 0건(재평가율 0%), 추가 비용·시간 0.** 경계 사례로 넣은 누락형 D1-03 도 Claude 가 사라진 내용 대신 답변의 해당 구절을 인용했다.
- 재평가율 0%는 이 20문항에서 발생하지 않았다는 뜻이며 재평가 경로가 필요 없다는 뜻은 아니다. 재평가 후 PASS·근거 있는 FAIL·미완료, 재평가 API 오류, 다른 FAIL 유지는 모의 검증으로만 확인됐다.

| 재평가 추가 비용 | $0 (재평가 없음). 참고로 검색 없는 호출 1회가 평균 $0.10 |

비용의 대부분은 검색 결과·열어 본 원문이 같은 요청 안에서 반복해 입력으로 계산되는 데서 나온다. 첫 요청 입력은 274k 인데 실제 입력은 1.53M 이었고, 프롬프트 캐시는 쓰이지 않았다.

**정밀 평가 확대 시 추정 (20문항 실측 기반 — 장기 평균이 아님)**

| 규모 | 측정 평균 기준 ($0.36/문항) | 대부분 검색 한도까지 쓰는 경우 ($0.75/문항, 측정 최댓값) | 시간 (동시 4건) |
|---|---:|---:|---:|
| 1,000문항 | 약 $360 | 약 $750 | 약 2.2시간 |
| 2,000문항 | 약 $730 | 약 $1,500 | 약 4.4시간 |

검증 문항의 답변은 1~5문장으로 짧다. 실제 수집 답변이 길면 사실 주장·검색이 늘어 위쪽 범위에 가까워질 수 있다. 처리량 제한(rate limit)은 확인하지 않았다.

## 6. 4단계 진행 판단: **조건부 진행**

| 기준 | 판단 |
|---|---|
| 판정 구조 정상 작동 | 예 — 20/20 실행, 오류 0, 판정 미완료·재평가·검색 불가 경로는 모의 검증 통과, 저장·복원 정상 |
| 심각한 오판정·결과 유실 | 결과 유실 없음. 질문 판정 16/20 — 잘못된 FAIL 3, 잘못된 PASS 1. 4건 모두 원인이 확인된 서버·CODE 규칙(F1~F4)이며 해당 기준에서 Claude 의 판단 자체는 4건 모두 기대와 같았다 |
| J5 출처 검증 | 부분 — Claude 의 출처 판정은 4/4 맞았지만 서버 확정 단계 결함 2건(F1·F2)과 원문 수집 실패(F5) |
| 멀티턴 조건 승계 | 부분 — 승계·변경·작업 한정·AI 약속 무시는 정상, 문구 해제 미인식(F3), J6 이중 판정(F6) |
| 비용·시간 | 문항당 $0.36·31초. 1,000문항 약 $360~750, 동시 4건으로 약 2.2시간 — 감당 가능하나 F8 검토 권장 |
| 신규 회귀 오류 | 없음 — Python 1,489 통과·24 건너뜀·재현용 xfail 4, JavaScript 4개 통과 |

권장 순서: F1·F2·F3 수정(안전한 버그 수정) → F4·F5·F6·F7 정책 결정 → 같은 20문항을 다시 실행해 질문 판정 20/20 확인(기존 저장 호출은 재사용 불가 — 판정 규칙이 바뀌므로 새 호출 필요, 약 $7) → 4단계 착수. 20문항은 장기 평균이나 전체 정확도를 확정하기에 작은 표본이다.
