Python 코드는 실행하지 않습니다. 외부 URL의 사실성은 참조 연결 검사 범위에 포함하지 않습니다.

04 · 의미 평가 기준

04 / 08

의미 평가는 여섯 가지를 봅니다.

질문의 목적을 이해하고 답변의 내용을 판단합니다. J5·J6는 2026-10-06에 추가했습니다.

J1

의도 충족성

시킨 일을 실제로 했나?

비교 요청에 비교 결과를 제공했는지

J2

내용 적절성

대상·상황·목적에 맞나?

초등학생 수준에 맞게 설명했는지

J3

논리 타당성

설명과 결론이 모순되지 않나?

앞부분과 뒷부분의 방향 설명이 일치하는지

J4

충분성

필요한 핵심 내용이 있나?

장단점 요청에 단점까지 다뤘는지

J5

DATA 신뢰도

답변의 수치·날짜·통계가 실제와 맞나?

참조 데이터가 있으면 그것과, 없으면 확립된 사실과 대조

J6

LONG CONTEXT

긴 대화에서 처음 지시와 문맥을 끝까지 지켰나?

1턴의 이름·말투 지시가 30턴에서도 유지되는지

개수·분량·문법·계산처럼 CODE가 맡는 조건은 의미 판단에서 제외합니다.
J5는 값의 출처와의 일치만, J6는 분량·형식이 아닌 의미적 지시·문맥 유지만 봅니다.

05 · J 기준 선택

05 / 08

평가할 J는 LLM 없이 고릅니다.

자료 구간을 가리고 요청 문장을 추린 뒤, 등록된 단어·표현 패턴을 찾습니다.

초등학생도 이해할 수 있게 지구가 둥근 이유를
단계별로 설명해줘.
찾은 근거 (질문 · 답변 · 대화)선택한 기준평가할 것
항상 적용J1요청을 실제로 수행했는지
초등학생도 · 이해할 수 있게J2대상과 설명 수준이 맞는지
이유J3이유 설명의 논리가 맞는지
단계J4핵심 단계가 빠지지 않았는지
표현을 찾는 코드는 ‘평가 기준’을 선택하고,
의미 평가 엔진은 답변의 PASS / FAIL을 판단합니다.

현재는 정규식 기반입니다. 위 표는 선택 근거의 대표 예시입니다. J5 DATA 신뢰도는 답변 본문의 수치·날짜·통계 데이터(또는 참조 데이터)가 있을 때, J6 LONG CONTEXT는 대화 입력(conversation_id·turn)의 2번째 턴부터 앞 턴 대화를 함께 보내 평가합니다. 등록되지 않은 표현을 놓치거나 금지 대상 단어를 잘못 잡을 수 있어 기준 선택도 별도 검증이 필요합니다.
