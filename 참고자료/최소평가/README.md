## 읽는 법

- **기준을 한 번씩 보는 것**이 목적이면 17개로 충분하다(기준 많은 질문부터 고르면 된다).
- **모델 순위·통과율**이 목적이면 17·37개로는 정밀과 다르다 — 기준이 많은 질문은 어려운 질문이라 통과율이 모두 낮아지고(24~38%), 순위도 뒤집힌다. 순위가 안정되는 데는 약 250개가 필요했다.
- 즉 "기준 많은 순"은 **커버리지는 빨리 채우지만 순위는 빨리 안정시키지 못한다**. 적은 수로 순위까지 보려면 기준 수가 아니라 난이도·종류를 섞어 뽑는 방법을 따로 시험해야 한다.
