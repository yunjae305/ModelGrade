요구사항 1 · 2

질문 수는 어떻게 정했나

질문 유형 7개 × 30개 방식은 근거가 없어 버렸습니다. 대신 가장 아래 단계 평가 기준이 몇 번씩 평가되는지, 질문 수를 늘려 갈 때 결과가 언제 안정되는지로 다시 정했습니다.

1

평가 기준을 가장 아래 단계까지 나눴다

CODE 평가 · 규칙으로 자동 판정 대분류 3 → 중분류 8 → 소분류 28 무결성 · 요구 조건 준수 · 수치 데이터. 질문이 거는 조건 종류로 나누면 37개
LLM 의미 평가 · 평가 모델이 판정 대분류 8 → 중분류 30 → 소분류 44 J1 의도 충족 ~ J8 첨부파일 활용. J6 멀티턴, J7 롱컨텍스트(272K 토큰 이상) 포함
80개 질문을 보고 적용 여부를 셀 수 있는 세부 기준 = CODE 37 + LLM 43 평가 기준은 총 72개(CODE 28 + LLM 44). 80개는 답변으로만 정해지는 8개(CODE 7 + J5-3.a)를 빼고 CODE 소분류 17개를 질문 조건 37개로 나눠 센 단위라 72와 다릅니다
2

기준을 겨냥해 질문을 만드는 프롬프트를 정했다 (생성기 v1.4)

GPT에게 80개 기준의 정의와 판정 규칙을 그대로 주고 질문을 만들게 합니다. 프롬프트의 규칙마다 이유가 있습니다.

기준마다 인식 규칙과 예시 질문을 그대로 넣음규칙에 맞는 표현이 아니면 CODE 검사가 아예 적용되지 않기 때문
한 질문이 최대 8개 기준을 함께 노림기준마다 질문을 따로 만들면 질문 수와 비용이 커짐. 서로 막는 기준(빈 출력, 모순 조건)은 분리
질문마다 틀리기 쉬운 지점과 난이도, 어려움 3분의 1 이상이전 시험에서 GPT가 대부분 100%가 나와 모델 간 차이가 보이지 않았기 때문
기준마다 적용 질문이 10개가 될 때까지 추가 생성질문 수를 먼저 정하지 않고, 기준별 평가 횟수로 질문 수가 정해지게 함
10턴 대화 10개, 27만 토큰 이상 긴 문서 질문 10개는 따로 생성질문 수만 지정한 300개 세트에서는 이 둘이 1개씩만 들어가 멀티턴(J6)·롱컨텍스트(J7)를 평가할 수 없었기 때문

결과: 질문 326개(대화형 질문 포함 425번 주고받음). 80개 기준 중 79개가 10번 이상 적용되고, 글자 수 조건만 7번이었습니다 — 10/14 점검에서 "공백 포함 N자" 인식 누락으로 밝혀져 수정 후 45번(요구사항 7).

질문 수만 지정해 따로 만든 300개 질문을 같은 방법으로 채점한 결과입니다. 여기서 AIONA는 빈 답 요구 질문 8개와, 첨부 2개를 올렸다가 답이 멈춘 질문 1개를 빼 291개입니다. Gemini는 출력 한도에 걸려 끝까지 못 받은 대화 1개를 빼 299개입니다.

5

질문을 적게 쓰면 점수가 얼마나 틀어지나

"질문을 50개만 썼다면 결과가 어땠을까?"를 확인했습니다. 질문을 새로 만들어 다시 평가하지 않고, 이미 채점한 326개 결과에서 질문을 골라 다시 계산하는 방법입니다.

  1. 326개 채점 결과를 준비모델마다 질문별 PASS·FAIL이 이미 있음
  2. 그중 50개를 무작위로 골라 점수 계산고른 질문이 다르면 점수도 달라짐
  3. 다른 조합으로 2,000번 반복50개로 평가하면 나올 수 있는 점수 2,000개가 모임
  4. 가운데 95%가 들어가는 범위를 봄이 범위가 좁을수록 질문 수가 충분하다는 뜻

질문 수별로 나올 수 있는 점수 범위

막대 = 2,000번 중 95%가 들어간 점수 범위 · 점 = 326개 전체로 채점한 점수

질문 50개로 평가하면 AIONA는 80~98%, GPT는 84~100% 사이 어느 점수든 나올 수 있습니다. 두 모델 범위가 대부분 겹치므로 50개로는 "GPT가 AIONA보다 낫다"고 말하기 어렵습니다. 200개면 AIONA 85~94%, GPT 90~97%로 좁아지고, 300개로 늘려도 범위가 거의 줄지 않습니다.

같은 방법으로 10개부터 326개까지 모든 구간을 계산한 결과입니다. 왼쪽은 고른 질문 안에 80개 세부 기준 중 몇 개가 한 번이라도 들어가는지, 오른쪽은 위 점수 범위의 절반(점수 오차)입니다.

시험되는 세부 기준 수 (80개 중)

질문 50개면 평균 70개만 들어가 10개 기준은 시험되지 않습니다. 200개부터 80개 모두 들어갑니다.
