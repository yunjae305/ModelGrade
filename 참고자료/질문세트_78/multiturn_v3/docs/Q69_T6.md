## 28. 회원 게시판 운영 규칙 '글 형식' 조항 발췌(류지안이 보낸 것)

- 공지 글은 제목, 목차, 본문, 참고 순서로 쓴다.
- 목차는 글 맨 위에 두며, 목차의 각 줄은 본문에 실제로 있는 소제목으로만 내부 링크를 건다. 링크 이름은 소제목 글자와 같아야 한다.
- 소제목은 되도록 짧은 한 낱말로 쓴다.
- 각주는 본문 표시와 글 맨 아래 정의를 함께 둔다. 정의 없는 각주 표시, 표시 없는 정의를 남기지 않는다.
- 출처 번호를 쓰면 글 끝에 번호별 목록을 둔다. 목록에는 원래 기록의 제목을 쓴다.
- 접는 칸(details · summary 태그)은 여는 태그와 닫는 태그의 짝을 맞춘다. 접는 칸 안에는 코드 구획을 넣지 않는다.
- 코드 구획은 한 글에 하나만 쓴다. 구획을 여는 표시와 닫는 표시를 모두 둔다. 코드 구획에는 복사해 쓸 문장만 넣고, 링크 · 각주 · 태그를 넣지 않는다.
- 사람의 연락처를 글에 적지 않는다. 문의는 담당자 이름과 창구로 안내한다.
- 글을 고칠 때는 고친 날짜를 제목 옆에 적는다.
- 행사 글 제목에는 대괄호 말머리를 붙인다.
- 회의방 주소는 공지 본문과 댓글에 적지 않는다.
- 이미지에 담은 내용은 본문 글자로도 적는다.
- 고정 공지는 한 번에 하나만 두며, 고정을 바꿀 때는 원래 고정 글 담당에게 미리 알린다.

- 정기 공부방 쉬는 시간: "10분 쉬겠습니다. 카메라는 켜 두셔도 되고 꺼 두셔도 됩니다."
