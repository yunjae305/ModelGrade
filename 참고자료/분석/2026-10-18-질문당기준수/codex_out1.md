**범위와 허용 이탈률은 다음 결정 규칙으로 고르는 것을 권합니다.**

1. **분모와 목표 배치를 먼저 고정합니다.**

   최종 질문 수가 326개라면 단일·대화 수를 먼저 정합니다. 대화는 현재처럼 2턴과 10~11턴을 한데 묶지 않고 별도로 다룹니다.

   단일 질문의 범위 이탈률은 다음처럼 정의합니다.

   \[
   r(S;a,b)=
   \frac{\#\{i\in S_{\mathrm{single}}:k_i<a\ \text{또는}\ k_i>b\}}
   {N_{\mathrm{single}}}
   \]

   조건은 `r ≤ t/100`입니다. 따라서 프롬프트에는 **“범위 밖 질문은 전체 단일 질문의 t% 이하”**라고 쓰는 편이 정확합니다. 이 비율은 음수가 없으므로 `±t%`는 맞지 않습니다.

   기존 `outside_pct`는 현재 표본에서 제외되는 비율입니다. 새 프롬프트의 생성 이탈률은 별도로 측정해야 합니다.

2. **커버리지는 범위 안과 밖을 합친 실제 배치에 겁니다.**

   질문–기준 적용 행렬을 \(A_{ij}\)라 하면 다음을 요구합니다.

   \[
   \sum_{i\in S}A_{ij}\ge m_j
   \]

   탐색용 정책 초안으로는 모든 변동 기준에 독립 사례 10개, 중요 기준에는 20개를 둘 수 있습니다. 이는 통계적으로 충분하다는 보장이 아니라 운영상 최소 노출량입니다.

   J6는 독립 대화 수로, J7은 서로 다른 문서에 걸친 사례 수로 관리합니다. 범위 밖 질문은 부족한 기준을 채우는 데 사용할 수 있으며, 그 질문의 성능도 최종 지표에 포함합니다.

4. **위험 상한을 정한 뒤 변별을 최적화합니다.**

   - 전부 FAIL 비율의 단측 95% 상한 ≤ 30%
   - 전부 PASS 비율의 단측 95% 상한 ≤ 50%

   **30%·50%·기준별 10회 같은 값은 데이터가 발견한 최적값이 아니라 사전에 정할 정책값**입니다. 값을 달리한 민감도 분석을 함께 제시해야 합니다.

5. **정수 범위와 t를 모두 조사하되, 선택 순서를 고정합니다.**

   > 유형별 목표 비율로 표준화한 변별률의 신뢰하한 최대 → 최고값에서 사전 허용차 3%p 이내이면 범위 폭 최소 → 그다음 필요한 이탈 허용치 최소.

   3%p도 사전 정책값입니다. 해가 없으면 “해 없음”으로 보고하고, 부족한 기준이나 표본을 명시해야 합니다.

**추가 실험은 동일한 기본 질문의 변형을 비교하는 방식이 적합합니다.**

같은 주제·기본 난이도·자료·J5 검증 조건을 유지하면서 적용 기준 수를 단계적으로 바꿉니다. 추가하는 기준 종류도 순환시켜 “기준 수 증가”와 “특정 어려운 기준 추가”를 분리합니다. 생성 후 실제 k를 검사하고, 기준들이 함께 발생해 특정 k를 만들 수 없다면 불가능한 조합으로 기록합니다.

현재 단일 질문이 존재하는 범위에 대응해 **새 정의 `k_variable=1~10`을 우선 촘촘하게 조사**하고, 더 높은 값은 자연스러운 질문을 만들 수 있는지 확인하며 확장하는 안을 권합니다.

| 목적 | 필요한 표본의 기준 |
|---|---:|
| 후보를 줄이는 탐색 실험 | k별 신규 30개, 10수준 총 300개 |
| k별 비율을 95% 수준에서 약 ±10%p로 추정 | 독립 표본 약 97개/k, 실무상 100개/k |
| 약 ±5%p로 추정 | 독립 표본 약 385개/k |
| 두 독립 후보의 15%p 차이 탐지 | 양측 5%·검정력 80% 근사로 약 175개/후보 |

비율 추정 표본 수는 \(n\approx1.96^2\times0.25/e^2\)의 보수적 근사입니다. 다중 비교·군집 상관·유형별 분석이 추가되면 더 필요합니다. 짝지은 비교의 표본 수는 탐색 실험에서 얻은 불일치율로 다시 계산해야 합니다. [NIST 표본 수 설명](https://www.itl.nist.gov/div898/handbook/ppc/section3/ppc333.htm)

따라서 **300개는 탐색용 최소 출발안이며 확정용 표본 수가 아닙니다.** 세 모델 답변은 900개가 되지만 독립 질문 수는 300개입니다. `k_variable=0` 기준선과 대화·서로 다른 긴 문서를 사용하는 커버리지 실험은 별도로 추가해야 합니다.

우선순위는 다음과 같습니다.

1. **미완료 PASS, AIONA 수집 오류, 재개 요약 불일치, 확인된 CODE 오판을 먼저 해결합니다.**
2. **고정 CODE 3개를 제외할지 정하고, k·커버리지·통과율의 평가 단위를 통일합니다.**
3. **단일·짧은 대화·긴 대화를 분리하고, 실제 독립 사례 수로 커버리지를 다시 계산합니다.**
4. **J5 포함/제외 및 실패 사유별 분석, 유형·난이도별 분석으로 후보를 좁힙니다.**
5. **가변 k 1~10에 30개씩 통제 실험을 하고, 후보 경계에 표본을 추가합니다.**
6. **새 검증자료와 실제 생성 배치에서 범위·이탈률·커버리지 조건을 확인한 뒤 프롬프트 값을 확정합니다.**
