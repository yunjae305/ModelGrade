## 특히 봐 주었으면 하는 것
- DualJudgeClient 가 기존 호출자(`_case_request` 가 넘기는 kwargs: state, questions, cancel_event, images)와 맞는가. Jev 에는 Luna 용 state 를 그대로 보내는데(`answer_citations_unchecked`, `attachments`, `image_attached` 등 들어 있음) 문제가 없는가.
- 재판정 호출(`self.luna.system_one(state, {cid: questions[cid]})`)에서 openai 클라이언트가 J5 없는 부분 집합도 정상 처리하는지(`search_requested`, `output_schema`, `citation_review`).
- 보류된 항목을 `parse_decisions` 가 UNVERIFIED 로 읽고, `apply_final_decision_policy` 가 다시 바꾸지 않는지. 집계·이벤트·화면에서 보류가 FAIL 로 새는 곳이 있는지.
- `_finish` 의 비용 부분 합치기: Jev 호출(calls[1])의 모델 이름·usage 가 `cost_reporting` 로 제대로 가는지. Jev 단가가 없어 '미확인'으로 남는 것은 알고 있음.
- `_in_answer` 느슨한 대조의 거짓 양성 위험(짧은 주장·숫자만 있는 주장).
- 이미지 블록 삽입이 `prompt_cache_breakpoint`(DEFAULT_MODEL 만) 와 충돌하지 않는지, Responses API 입력 형식(input_text/input_image)이 맞는지.
- 멱등성·예외 경로·취소(cancel_event) 처리.
