```python
def return_status(returned):
    if returned is True:
        return "완료"
    if returned is False:
        return "확인 필요"
    if returned is None:
        return "상태 미상"
    raise ValueError("반납 여부는 True, False 또는 None이어야 합니다.")

print(return_status(True))   # 완료
print(return_status(False))  # 확인 필요
print(return_status(None))   # 상태 미상
```

## 원리와 관찰 순서

### 원본과 캐시

📌 **원본 데이터**는 서버가 기준으로 삼아 보관하는 실제 값이고, **캐시**는 빠르게 보여 주려고 잠시 저장해 둔 복사본입니다. 화면은 원본을 매번 직접 읽기보다 캐시에 있는 값을 먼저 보여 줄 수 있습니다.

관찰하신 순서를 이 원리로 설명하면 다음과 같습니다.

1. 서버의 값을 수정합니다.
2. 화면이 갱신된 원본 대신 이전에 저장된 캐시를 읽어 예전 값이 보입니다.
3. 캐시를 비우면 그 사본을 더는 사용할 수 없게 됩니다.
4. 화면이 서버에서 값을 다시 받아오면서 새 값이 표시됩니다.

### 물리적 밝기와 지각
**물리적 밝기**는 화면에서 나오는 빛의 양을 가리키고, **지각된 밝기**는 눈과 뇌가 그 빛을 주변 환경과 함께 받아들인 결과예요. 주변 조명을 끄면 화면의 실제 밝기가 자동으로 바뀌는 것은 아니지만, 어두운 주변에 비해 화면이 더 밝게 두드러질 수 있습니다.

원인 설명의 순서는 중요해요. 먼저 바뀐 조건은 **주변 조명**이고, 그 결과 화면과 주변의 밝기 차이가 커졌습니다. 어두운 환경에 눈이 적응하는 과정도 화면을 더 강하게 느끼는 데 영향을 줄 수 있지만, 화면 자체의 밝기가 변했다고 결론 내릴 근거는 아닙니다.

어두운 방에서 손전등을 켜면, 밝은 방에서 같은 손전등을 켰을 때보다 빛이 훨씬 두드러져 보입니다. 손전등의 빛이 더 강해져서라기보다, **주변이 어두워져 빛과 배경의 차이가 커졌기 때문**이에요.

- 손전등에서 나오는 빛 → 화면의 물리적 밝기

def remove_duplicates(items):
    seen = set()
    result = []

    for item in items:
        name = item["name"]

        if name not in seen:
            seen.add(name)
            result.append(item)

    return result

문자열로 된 도서 번호를 사전식 오름차순으로 정렬하는 함수입니다. `sorted()`를 사용하면 원본 목록을 변경하지 않고 새로운 목록을 반환할 수 있습니다.

```
def sort_book_numbers(numbers):
    return sorted(numbers)


# 사용 예
book_numbers = ["010", "002", "10", "001", "02"]

result = sort_book_numbers(book_numbers)

print("정렬 결과:", result)
print("원본 목록:", book_numbers)

# 정렬 결과: ['001', '002', '010', '02', '10']
# 원본 목록: ['010', '002', '10', '001', '02']
```

### 설명

1. \*\*`sorted(numbers)`\*\*는 문자열을 사전식 오름차순으로 정렬합니다.
2. 문자열을 정수로 변환하지 않으므로 `"001"`처럼 앞에 있는 0이 그대로 보존됩니다.
3. `"002"`와 `"02"`는 서로 다른 문자열로 취급합니다.
4. `sorted()`는 새로운 목록을 반환하므로 원본 목록은 변경되지 않습니다.

주의: 사전식 정렬은 숫자 크기순 정렬과 다릅니다. 예를 들어 `"10"`은 `"2"`보다 앞에 옵니다.

다음 함수는 두 예약 시간대가 겹치는지 확인합니다.

- 겹치면 `True`를 반환합니다.
- 겹치지 않으면 `False`를 반환합니다.
- 한 예약의 종료 시각과 다른 예약의 시작 시각이 같으면 겹치지 않는 것으로 처리합니다.
- 입력값은 변경하지 않습니다.

### 파이썬 코드

```
def is_overlapping(start1, end1, start2, end2):
    return start1 < end2 and start2 < end1


# 사용 예: 첫 번째 예약 60~90분, 두 번째 예약 90~120분
result = is_overlapping(60, 90, 90, 120)

print(result)  # False
```

### 코드 설명

1. `start1`, `end1`은 첫 번째 예약의 시작과 종료 시각입니다.
2. `start2`, `end2`는 두 번째 예약의 시작과 종료 시각입니다.
3. `start1 < end2`는 첫 번째 예약이 두 번째 예약의 종료 전에 시작하는지 확인합니다.
4. `start2 < end1`은 두 번째 예약이 첫 번째 예약의 종료 전에 시작하는지 확인합니다.
5. 두 조건이 모두 참이면 예약 시간이 겹치므로 `True`를 반환합니다.
