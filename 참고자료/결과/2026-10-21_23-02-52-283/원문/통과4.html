# 생활강좌 신청 안내: 처음 신청하는 성인

처음 신청하는 성인은 **수강 신청서**를 제출하면 됩니다. 주민 확인서와 참여 동의서는 모든 성인에게 필요한 서류가 아니며, 수강료는 안내문에 금액이 없어 **미기재**입니다.

## 제출 서류와 방법

| 서류 | 필요한 대상 | 제출 방법 | 제출 부서·장소 | 안내 사항 |
|---|---|---|---|---|
| 수강 신청서 | 모든 신청자 | 현장 또는 온라인 제출 | 접수창구 | 중복 제출은 필요하지 않음 |
| 주민 확인서 | 감면 신청자 | 현장에서 원본 확인 | 교육지원실 | 확인 후 원본 반환 |
| 참여 동의서 | 미성년 신청자 | 현장 제출 | 학습지원실 | 주민 확인서와 별도 서류 |

## 성인 신청자가 확인할 점

감면을 신청하지 않는 성인은 **주민 확인서나 참여 동의서를 일괄 제출할 필요가 없습니다**. 감면을 신청한다면 주민 확인서를 현장에 가져가 교육지원실에서 원본 확인을 받으면 됩니다.

📌 교육지원실과 학습지원실은 서로 다른 제출 부서이므로 서류별 제출처를 확인해 주세요. **수강료는 별도 공지**라고만 안내되어 있어 금액은 미기재입니다.첨부 문서의 현재 확인 범위는 2026년 9월 25일 반영 내용입니다.

답변
`None`만 걸러내고 숫자 `0`과 `False`는 보존하며, 원본 목록은 그대로 두는 함수예요.

## 함수와 사용 예

```python
def remove_none(values):
    return [value for value in values if value is not None]

measurements = [12, None, 0, False, 7, None]
filtered = remove_none(measurements)

print(filtered)       # [12, 0, False, 7]
print(measurements)   # [12, None, 0, False, 7, None]
```

## 동작 원리

- `value is not None`은 값이 `None`인지 **정확히 확인**합니다. 그래서 `0`이나 `False`처럼 거짓으로 취급되는 값도 삭제하지 않아요.
- 대괄호 안의 조건에 맞는 값만 모아 **새 목록**을 만듭니다. 따라서 함수에 전달한 `measurements`는 수정되지 않습니다.
- `filtered`에는 `None`이 빠진 결과가 저장되고, 원본 목록은 그대로 출력됩니다.

## 원리와 관찰 순서

### 원본과 캐시

📌 **원본 데이터**는 서버가 기준으로 삼아 보관하는 실제 값이고, **캐시**는 빠르게 보여 주려고 잠시 저장해 둔 복사본입니다. 화면은 원본을 매번 직접 읽기보다 캐시에 있는 값을 먼저 보여 줄 수 있습니다.

관찰하신 순서를 이 원리로 설명하면 다음과 같습니다.

1. 서버의 값을 수정합니다.
2. 화면이 갱신된 원본 대신 이전에 저장된 캐시를 읽어 예전 값이 보입니다.
3. 캐시를 비우면 그 사본을 더는 사용할 수 없게 됩니다.
4. 화면이 서버에서 값을 다시 받아오면서 새 값이 표시됩니다.

이 순서만으로는 수정된 값이 처음부터 원본에 저장되지 않았다고 단정할 수 없습니다. 캐시가 어디에 있었는지, 수정 후 서버 응답이 어떻게 처리됐는지는 관찰 내용만으로 확인되지 않습니다.

## 도서관 대출 목록에 비유

### 각 요소의 대응

도서관 전산실에 **최신 대출 기록 원본**이 있고, 안내 데스크에는 그 내용을 미리 복사해 둔 **대출 목록 사본**이 있다고 생각해 보세요. 전산실에서 기록을 바꿔도 데스크의 사본을 바로 갱신하지 않으면, 이용자는 한동안 이전 목록을 보게 됩니다. 사본을 치우고 전산실 기록을 다시 확인하면 최신 목록이 보입니다.

- 전산실의 최신 대출 기록 → **서버의 원본 데이터**
- 안내 데스크에 둔 목록 사본 → **캐시**
- 이용자가 보는 대출 목록 → **화면에 표시된 값**
- 사본을 치우고 최신 기록을 다시 확인하는 일 → **캐시를 비운 뒤 서버에서 다시 가져오는 과정**
