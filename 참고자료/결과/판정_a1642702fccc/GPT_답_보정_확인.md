````
아래 함수는 목록에서 `name`이 같은 항목은 처음 등장한 항목만 남기고, 나머지는 제거합니다.

def remove_duplicates(items):    seen = set()    result = []    for item in items:        name = item["name"]        if name not in seen:            seen.add(name)            result.append(item)    return result# 사용 예data = [    {"name": "솔", "v": 2},    {"name": "별", "v": 1},    {"name": "솔", "v": 8}]filtered = remove_duplicates(data)print(filtered)# [{'name': '솔', 'v': 2}, {'name': '별', 'v': 1}]print(data)# 원본 목록은 변경되지 않습니다.

**후**

````
아래 함수는 목록에서 `name`이 같은 항목은 처음 등장한 항목만 남기고, 나머지는 제거합니다.

```python
def remove_duplicates(items):
    seen = set()
    result = []

    for item in items:
        name = item["name"]

        if name not in seen:
            seen.add(name)
            result.append(item)

    return result


# 사용 예
data = [
    {"name": "솔", "v": 2},
    {"name": "별", "v": 1},
    {"name": "솔", "v": 8}
]

filtered = remove_duplicates(data)

print(filtered)
# [{'name': '솔', 'v': 2}, {'name': '별', 'v': 1}]

print(data)
# 원본 목록은 변경되지 않습니다.
```

### 초보자를 위한 설명

1. `seen = set()`: 이미 등장한 이름을 저장합니다.
2. `result = []`: 중복을 제거한 결과를 담을 새 목록입니다.
3. `if name not in seen`: 처음 등장한 이름인지 확인합니다.
4. `result.append(item)`: 처음 등장한 항목만 결과에 추가합니다.
5. `return result`: 중복 제거가 완료된 목록을 반환합니다.

### 실행 결과

| name | v | 처리      |
| ---- | - | ------- |
| 솔    | 2 | 유지      |
| 별    | 1 | 유지      |
| 솔    | 8 | 제거 (중복) |

핵심: `솔`의 첫 기록인 `v=2`만 유지하고 `v=8`은 제거합니다. 원래 순서를 보존하며, 입력 목록도 변경하지 않습니다.
