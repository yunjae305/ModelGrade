# 질문 세트 78 — v3.3 + 멀티턴 v3 (qs-2026-10-21-mt3, 2026-10-21)

v3.3 세트(`../질문세트_78_생성프롬프트v3.3`, qs-2026-10-21)에서 **10턴 대화 11개(Q1~Q10 · Q69)만 바꾼** 세트입니다. 단일 질문 67개(일반 · 빈 출력 · 긴 문서 · 첨부)는 v3.3 과 글자까지 같아서, 그 질문들에 이미 받은 답은 그대로 쓸 수 있습니다.

## 왜 바꿨나
- 멀티턴 기준 v3(질문생성 프롬프트 v3.4): 한 턴(질문+답)이 1만 토큰 이상인 턴이 10개 이상이고 대화 전체가 10만 토큰 이상일 때 멀티턴(J6)으로 인정합니다. 답 길이는 모델마다 달라, **질문만으로** 턴마다 1만 토큰을 넘게 했습니다.
- v2 대화 11개는 한 틀에 주제만 바꾼 비슷한 흐름이었습니다. 대화마다 턴 순서를 다르게 짰습니다.

## 무엇이 바뀌었나
- 110개 턴마다 그 턴 과제에 실제로 쓰이는 **서로 다른 문서**를 `[붙여 넣은 자료] … [자료 끝]` 으로 붙였습니다. 문서 종류는 준비 회의록 · 운영 확인 기록 · 비품 대장과 견적 메일 · 점검 일지 · 지난 회차 피드백 · 게시 담당 메일 · 변경 공문 · 자리 운영 기준 · 게시판 의견 · 일정표 개정 자료 · 다른 부서 일람표입니다. 문서는 `multiturn_v3/docs/Q<번호>_T<턴>.md` 에 있습니다.
  - 같은 문단 반복, 채움 글, 앞 턴 자료 다시 붙이기는 없습니다.
  - 계산 결과 같은 그 턴의 정답은 문서에 미리 적지 않았습니다.
  - 행사 날짜와 연락처는 미정입니다.
- 요청 문장은 v2 의 검증된 문구를 그대로 씁니다(인식기가 알아봄). 대화는 두 종류입니다.
  - **A형 7개**: 1턴에 A안 · B안을 비교해 추천합니다.
  - **B형 4개**: 1턴은 조건만 정리하고, 대신 원리 설명과 기록 요약을 둘 다 넣습니다.
  - 모든 대화에 들어가는 턴: 표 계산, 안내문 초안, 형식 수정, 조건 변경 수정, 근거 없는 반박(자료는 수치 없는 의견 글), 최종 일정.
  - 대화에 따라 들어가는 턴: 원리 설명, 기록 요약, 자료 대조(일부러 세 곳 틀린 일람표), 없는 첨부 묻기.
