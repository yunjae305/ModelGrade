한송이 주무관님, 게시 담당 서지안입니다.

보내 주신 안내문 초안 잘 받았습니다. 내용은 그대로 두고, 누리집 게시판에 올리기 전에 형식을 게시판 규정에 맞춰야 해서 연락드립니다. 지난 7월 낭독회 이후 누리집 게시판 형식 규정이 바뀌어서, 이번 안내문이 새 규정을 처음 적용하는 저녁 행사 게시물이 됩니다.

바뀐 규정 가운데 이번 안내문에 해당하는 것은 다섯 가지입니다.

첫째, 제목이 두 개 이상인 긴 안내문은 맨 위에 목차를 둡니다. 목차의 각 항목은 본문의 실제 제목으로 바로 내려가는 내부 링크여야 합니다. 목차에 적은 이름과 본문 제목 이름이 글자 하나까지 같아야 링크가 작동합니다.

둘째, 본문에 덧붙일 설명은 각주로 뺍니다. 본문 문장 끝에 각주 표시를 달고, 같은 이름의 각주 정의를 문서 맨 아래에 둡니다. 표시만 있고 정의가 없거나, 정의만 있고 표시가 없으면 게시판에서 오류로 보입니다.

셋째, 도서관 내부 기록을 근거로 숫자나 조건을 적을 때는 대괄호 숫자로 출처 번호를 달고, 문서 끝에 같은 번호의 출처 목록을 둡니다. 본문 번호와 목록 번호가 서로 맞아야 합니다.

넷째, 문의 부분은 접는 칸에 넣습니다. 처음에는 '문의'라는 제목만 보이고, 누르면 펼쳐지는 방식입니다. 본문이 길어지지 않게 하려는 것입니다.

다섯째, 담당자가 데스크 일지에 복사해 붙일 운영 메모는 게시물 맨 끝에 편집기의 고정폭 글자 칸(편집기에서는 '코드 칸'이라고 부릅니다)에 넣습니다. 이 칸은 게시판에서 회색 상자로 보이고, 오른쪽 위 복사 단추로 한 번에 복사됩니다.

초안 본문에 '접수'와 '문의' 이야기가 섞여 있는데, 형식 규정에 맞추려면 이 둘을 각각 제목으로 세워 두는 편이 좋겠습니다. 목차도 그 제목을 가리키게 하면 됩니다.

## 2. 9월 19일(토) 10:45 — 서지안 → 한송이(참조: 표지훈)

제목: 누리집 게시판 형식 규정 발췌(긴 안내문 부분)

누리집 게시판 형식 규정 가운데 긴 안내문 부분을 옮깁니다. 누리집 관리 담당 표지훈 주무관을 참조로 넣었습니다.

### 2-1. 목차

- 제목이 두 개 이상이면 본문 맨 위에 목차를 둔다.
- 목차 항목은 대괄호 안에 보이는 이름, 괄호 안에 샵 기호와 제목 이름을 붙인 내부 링크 형태로 쓴다. 예를 들어 '접수'라는 제목으로 가는 항목은 보이는 이름도 접수, 링크 대상도 샵 기호 뒤 접수로 쓴다.
- 링크 대상이 되는 제목은 본문에 실제로 있어야 한다. 목차에만 있고 본문에 없는 제목은 쓰지 않는다.
- 제목 이름에 띄어쓰기가 있으면 링크 대상에서는 띄어쓰기를 하이픈으로 바꾼다. 가능하면 제목은 한 낱말로 짓는다.

### 2-2. 각주

- 각주 표시는 대괄호 안에 꺾쇠 기호와 각주 이름을 넣는다.
- 각주 정의는 문서 맨 아래, 출처 목록보다 위에 둔다. 정의 줄은 각주 표시와 같은 모양 뒤에 쌍점을 붙이고 설명을 쓴다.
- 각주 이름은 한 낱말로 짓고, 같은 문서 안에서 같은 이름을 두 번 쓰지 않는다.

### 2-3. 출처 번호

- 도서관 내부 기록을 근거로 쓸 때만 단다. 바깥 누리집이나 언론 기사를 출처로 달지 않는다.
- 본문에는 대괄호 숫자만 쓰고, 문서 끝 '출처' 목록에 같은 숫자와 기록 이름을 적는다.
- 출처 목록의 기록은 도서관 안에서 실제로 작성된 기록이어야 한다.

### 2-4. 접는 칸

- 접는 칸은 details 태그로 감싸고, 그 안 맨 앞에 summary 태그로 보이는 제목을 둔다.
- 여는 태그와 닫는 태그는 반드시 짝을 맞춘다. 닫는 태그가 빠지면 그 아래 본문 전체가 접힌다.
- 접는 칸은 코드 칸 안에 넣지 않는다. 코드 칸 안에서는 태그가 글자로 보일 뿐 접히지 않는다.

### 2-5. 운영 메모(코드 칸)

- 담당자가 복사해 쓰는 운영 메모는 게시물 맨 끝에 코드 칸 하나에만 넣는다.
- 코드 칸을 여는 표시와 닫는 표시를 모두 적는다. 닫는 표시가 빠지면 그 아래 내용이 모두 회색 상자에 들어간다.
- 코드 칸 안에는 각주 표시, 출처 번호, 내부 링크, 태그를 넣지 않는다. 코드 칸 안에서는 작동하지 않고 글자 그대로 복사되기 때문이다.
- 운영 메모는 담당자가 그대로 복사해 일지에 붙이는 문장으로 쓴다.
