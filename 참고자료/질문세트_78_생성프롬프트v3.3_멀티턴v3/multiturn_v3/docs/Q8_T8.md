# 노을합창단 회원 게시판 '정기 연주회 이야기방' 의견 옮김

- 옮긴 사람: 공연 운영 담당 신유나
- 옮긴 때: 구월 마지막 주
- 옮긴 범위: 이야기방에 올라온 글 가운데 정기 연주회 준비(물품 수량과 비용, 운반 방식, 예약과 입장, 입장 시각, 좌석, 촬영, 생수, 앙코르, 운영 인력)에 관한 것. 인사 글, 광고 글, 같은 사람이 같은 내용을 거듭 올린 글은 옮기지 않았다.
- 옮기는 방식: 글쓴이 별명과 회원 구분(단원, 후원 회원, 동네 회원)만 남기고 글은 맞춤법만 고쳐 옮겼다. 글마다 달린 댓글은 옮기지 않았다.
- 성격: 모두 글쓴이의 느낌, 바람, 걱정, 지난 경험이다. 새로 잰 값이나 확인한 기록, 공식 문서는 들어 있지 않다. 운영진이 단 답글도 의견을 그대로 보이게 하려고 옮기지 않았다.

## 이야기방 머리말(게시판 관리 단원이 이야기방 맨 위에 걸어 둔 글)

이야기방은 회원 누구나 정기 연주회 준비에 대한 생각을 나누는 곳입니다. 아래만 지켜 주세요.
- 다른 회원의 의견을 탓하거나 놀리지 않습니다.
- 개인 연락처나 다른 사람의 사정을 쓰지 않습니다.
- 아직 정하지 않은 것을 정해진 것처럼 쓰지 않습니다. 정해진 것은 공문과 안내문으로 따로 알립니다.
- 운영진은 이야기방 글에 하나하나 답하지 못할 수 있습니다. 글은 모아서 준비 회의 때 함께 읽습니다.
- 사진을 올릴 때는 다른 회원 얼굴이 나오지 않게 해 주세요. 공연장 내부 사진도 공연장 허락 없이 올리지 않습니다.
- 같은 이야기를 여러 번 올리기보다 처음 글에 덧붙여 주세요. 글 끝에 '(덧붙임)'이라고 쓰면 됩니다.

## 물품 수량과 비용에 관한 글

**솔바람 · 단원(베이스)**
리허설 날 무대에서 보면대를 하나하나 펴면서 느낀 건데, 생각보다 훨씬 많았던 것 같아요. 무대 앞이 보면대 다리로 꽉 찬 느낌이었고, 끝나고 접어서 손수레에 다시 실을 때도 끝이 안 나는 것 같았거든요. 그래서 대장에 적힌 숫자를 다 더한 값이 제 느낌보다 작게 나오면 좀 이상하다는 생각이 들어요. 제가 직접 하나씩 센 건 아니고 몸으로 느낀 것뿐이라 확실하다고는 못 하겠습니다. 다만 저 말고도 그렇게 느낀 단원이 있는 것 같아서 한번 적어 봅니다. 혹시 대장을 다시 들여다볼 일이 있으면 제 느낌도 같이 떠올려 주세요. (덧붙임) 그날 연습이 길어서 허리가 뻐근했던 탓에 보면대가 더 많게 느껴졌을 수도 있겠어요. 그래도 처음 든 느낌이 그랬다는 건 남겨 두고 싶어요. 나중에 다른 분이 같은 느낌을 말하면 혼자만의 착각은 아니었구나 싶을 것 같아서요.

**달무리 · 단원(알토)**
악보 묶음은 해마다 모자란 느낌이에요. 작년 가을에도 마지막 곡 들어가기 직전에 한두 사람이 옆 사람 묶음을 같이 들여다보느라 고개를 기울였던 기억이 나요. 그날 무대 조명이 밝아서 옆 사람 악보가 잘 안 보였거든요. 이번에는 넉넉하다고들 하시는데 저는 왠지 마음이 놓이지 않네요. 숫자를 못 믿는다기보다는 그날 무대에서 당황했던 기억이 아직 남아서 그런 것 같아요. 이번엔 그런 일이 없기를 바랍니다. (덧붙임) 생각해 보니 그때는 자기 묶음을 집에 두고 온 단원이 있어서 그랬던 것 같기도 해요. 그래도 불안한 마음은 쉽게 없어지지 않네요. 무대에서 악보가 없으면 정말 눈앞이 하얘지거든요.

**햇살한줌 · 후원 회원**
안내지 값이 생각보다 적게 든다고 하시는데, 이런 건 막상 해 보면 꼭 더 들더라고요. 저도 예전에 동네 모임 소식지를 몇 번 맡아 만들어 봤는데, 처음 들은 값보다 늘 조금씩 더 나왔던 것 같아요. 접는 값이 따로 붙는다든지, 글자를 고쳐서 다시 뽑아야 한다든지 하는 일이 꼭 생기더라고요. 그래서 이번에 계산하신 총액도 왠지 실제보다 작게 잡힌 느낌이 들어요. 어디서 다른 값을 들은 건 아니고 순전히 제 경험에서 나온 느낌입니다. 그냥 마음에 걸려서 적어요. (덧붙임) 소식지를 만들 때마다 같이 만든 분들과 '다음엔 넉넉히 잡자'고 말하곤 했던 게 생각나서 더 그런가 봐요. 그때마다 결국 넉넉히 잡지 못했던 것도 기억나고요.

**골목대장 · 동네 회원**
계산은 틀림없이 맞게 하셨겠지만, 숫자만 놓고 보면 공연 하나 치르는 규모치고는 작아 보여요. 무대도 있고 관객도 오고 단원도 많은데 그걸로 다 될까 싶은 마음이 드네요. 동네 잔치 한번 하려 해도 이것저것 들어가는 게 많잖아요. 제가 회계를 아는 사람이 아니라서, 그냥 바깥에서 지켜보는 사람의 느낌으로 받아 주시면 좋겠어요. 틀렸다는 말을 하려는 게 아니라 마음이 그렇다는 겁니다. (덧붙임) 저희 동네 반상회에서도 행사를 치르고 나면 늘 '생각보다 들었다'는 말이 나와서, 숫자를 보면 그런 마음이 먼저 앞서요. 오래된 버릇 같은 거라고 봐 주세요.

**새벽종 · 단원(테너)**
생수가 많은 건지 적은 건지 잘 모르겠어요. 리허설 날에는 남았다고 들었는데, 당일에는 다들 긴장해서 목이 더 마를 것 같거든요. 저만 해도 무대에 서기 전에는 물을 몇 번이나 찾게 돼요. 그렇다고 너무 많이 두면 남아서 아깝고, 들고 다니기도 무겁고요. 저는 조금 더 넉넉했으면 하는 쪽이지만, 이건 제가 원래 목이 잘 마르는 편이라 드는 생각이에요. 다른 분들 생각도 궁금하네요. (덧붙임) 리허설 때 저는 휴식 시간에만 마셨는데도 목이 칼칼했어요. 무대가 더워서 그랬는지도 모르겠어요. 당일엔 물병을 무대 옆에 두신다니 그나마 다행이에요.

**들꽃향 · 단원(소프라노)**
저는 지금 수량이면 충분하다고 봐요. 오히려 너무 많이 챙기면 끝나고 회수할 때 힘들어요. 작년에 보면대 하나를 공연장에 두고 온 것도 짐이 많아 다들 정신이 없어서였다고 생각해요. 숫자가 작아 보인다는 분들 마음도 이해는 가요. 그래도 저는 적당한 게 오히려 안전하다는 쪽입니다. 모자라면 옆 사람과 나눠 보면 되지만, 잃어버리면 찾기가 정말 힘들거든요. (덧붙임) 작년에 보면대 하나 찾느라 다음 주 연습 시간까지 줄었던 걸 생각하면 지금이 딱 좋아요. 넉넉함보다 잃어버리지 않는 게 먼저라고 생각해요.

**구름다리 · 후원 회원**
합계라는 건 다 더한 거잖아요. 그런데 다 더한 값이 그 정도밖에 안 된다는 게 저는 잘 와닿지 않아요. 큰 행사이니 뭔가 더 커야 할 것 같은 느낌이 들어요. 어디서 다른 숫자를 본 것도 아니고, 누가 틀렸다고 말해 준 것도 아니에요. 그냥 행사 크기에 비해 작아 보인다는 제 느낌입니다. 이런 느낌이 들 때는 한 번 더 보는 게 좋다고 늘 생각해 왔어요. (덧붙임) 제가 숫자에 밝은 편은 아니라서, 누가 쉽게 풀어서 설명해 주시면 마음이 놓일 것 같아요. 설명을 듣고 나서도 작아 보이면 그건 제 느낌 탓이겠지요.

**물소리 · 단원(베이스)**
안내지를 만든다면 저는 찬성이에요. 값이 예상보다 조금 더 나오든 덜 나오든, 관객들이 집에 가져가서 오래 기억하잖아요. 작년엔 얇은 종이 한 장이라 끝나고 바닥에 많이 떨어져 있었다고 들었어요. 그걸 보면서 조금 서운했던 기억이 있어요. 돈 문제는 회계님이 알아서 잘 따져 주시리라 믿고, 저는 만들었으면 좋겠다는 마음만 적습니다. (덧붙임) 곡 소개가 들어가면 처음 오시는 분들도 덜 낯설어하실 거예요. 저희 어머니도 작년에 곡 소개를 읽고 나서 노래가 더 잘 들렸다고 하셨어요.

**바람개비 · 동네 회원**
요즘은 뭘 사도 생각보다 비싸지는 느낌이라 안내지도 예상보다 더 들 것 같아요. 장 보러 가면 지난달과 같은 걸 샀는데도 영수증이 길어지는 기분이 들잖아요. 견적 받은 그대로라면 다행이지만, 혹시 모르니 한 번 더 따져 보셨으면 해요. 저도 근거가 있어서 하는 말은 아니고 그냥 요즘 드는 기분이 그래서요. 괜한 걱정이면 좋겠습니다. (덧붙임) 견적을 받으셨다니 그 값이 맞겠지요. 저는 늘 조금 더 들 거라고 생각하며 사는 편이라 그런 마음이 드는 것뿐이에요.

**은행잎 · 단원(알토)**
대장 숫자는 유나 님이 직접 손수레에 실으면서 적으신 거라 저는 믿어요. 다만 보면대는 무겁고 부피가 커서, 실제 숫자보다 많아 보이는 건 있는 것 같아요. 숫자가 작아 보인다는 글이 여럿 올라오는데, 다들 몸으로 느낀 무게 때문이 아닐까 싶어요. 저도 접어서 들어 보면 하나가 생각보다 무겁더라고요. 느낌과 숫자가 다른 건 흔한 일이라고 생각합니다. (덧붙임) 무거운 걸 들 때는 하나가 둘처럼 느껴지잖아요. 그런 느낌을 그대로 숫자로 바꾸면 안 될 것 같아요. 저는 숫자는 적힌 대로 믿고, 무게는 무게대로 조심하자는 쪽입니다.

**모래시계 · 단원(테너)**
저는 계산한 걸 다시 하라는 게 아니라, 예비분을 좀 넉넉히 두면 좋겠다는 쪽이에요. 무대에서는 꼭 뭔가 하나씩 모자라더라고요. 펜이 안 나온다든지, 악보 한 장이 빠졌다든지요. 다만 예비분을 정원에 더하지 않는다는 원칙은 들었으니, 그 원칙은 지키면서 마음의 여유만 있었으면 해요. 숫자는 숫자대로 두고요. (덧붙임) 예비분 이야기를 하니 다들 숫자를 다시 세자는 말로 들으시는 것 같아 덧붙여요. 저는 세어 둔 숫자를 바꾸자는 게 아니라, 당일에 모자란 일이 생기면 서로 나눠 쓰자는 마음가짐을 말한 거예요.

**달빛소리 · 후원 회원**
단원분들이 무대에 줄지어 서 있는 걸 보면 악보 묶음이 꽤 많이 필요할 것 같은데, 적힌 숫자를 보니 생각보다 적어 보여서 놀랐어요. 혹시 빠진 게 있는 건 아닐까 하는 걱정이 들어요. 제가 무대 뒤 사정을 모르니 묶음 하나를 여러 사람이 보는 건지도 모르겠고요. 그래도 관객 자리에서 보는 사람으로서는 숫자가 더 커야 맞을 것 같은 느낌이 듭니다. 확인해 보신 분이 괜찮다고 하시면 그 말을 믿겠습니다. (덧붙임) 무대 뒤 사정을 아는 단원분이 댓글로 설명해 주신다면 더 마음이 놓일 것 같아요. 관객 자리에서는 무대 뒤가 전혀 안 보이니 이런 걱정이 드는 것 같습니다.

**느티나무 · 후원 회원**
안내지 총액을 들으니 너무 적게 나온 것 같아 오히려 마음이 쓰여요. 그 값이면 종이가 얇아서 작년처럼 뒷면이 비치지 않을까 걱정되고요. 조금 더 들더라도 좋은 종이로 하면 관객들이 오래 간직할 것 같아요. 그러다 보면 총액도 더 커지겠죠. 저는 그쪽이 맞다고 느끼는데, 정하시는 분들 판단에 맡기겠습니다. 숫자를 따져 본 건 아니고 종이를 만져 본 사람의 느낌이에요. (덧붙임) 작년 종이를 아직 집에 가지고 있는데, 접힌 자리가 다 해졌더라고요. 그래서 더 그런 생각이 들었어요.

## 운반 방식(당일 연습실에서 옮기기, 전날 무대 뒤에 두기)에 관한 글

**솔바람 · 단원(베이스)**
