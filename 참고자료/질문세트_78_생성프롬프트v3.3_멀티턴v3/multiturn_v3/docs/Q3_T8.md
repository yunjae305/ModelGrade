## 메일 2 — 사업장 행사 안내 글 형식 규정

- 보낸 사람: 문하람
- 받는 사람: 오세린
- 참조: 배정연, 윤서진

편집위원회가 정한 사업장 행사 안내 글 형식 규정입니다. 행사 안내 글은 모두 이 순서와 방식을 따릅니다.

1. 제목: 행사 이름이 들어간 제목 하나. 제목에 검색어(예: '시음')가 들어가야 게시판 검색에 걸립니다.
2. 목차: 제목 바로 아래에 둡니다. 목차의 각 항목은 같은 글 안의 해당 제목으로 이동하는 내부 링크로 겁니다. 링크에 쓰는 이름은 실제 제목 글자와 똑같아야 합니다. 행사 안내 글에는 적어도 '신청'과 '문의' 두 항목이 목차에 있어야 하고, 글 안에도 '신청'과 '문의'라는 제목이 실제로 있어야 합니다.
3. 본문: 일시, 참여 조건 등 행사 내용. 본문 안에서 보충 설명이 필요한 낱말에는 각주 표시를 붙이고, 각주의 정의는 글 아래쪽에 둡니다. 각주 표시와 정의의 이름이 같아야 서로 이어집니다.
4. 출처 번호: 본문에서 사업장 기록을 근거로 든 곳에는 대괄호 번호를 붙이고, 글 아래쪽에 같은 번호로 출처 목록을 둡니다. 번호는 글에 붙인 기록만 가리키게 합니다.
5. 문의 칸: '문의' 절의 내용은 접고 펼칠 수 있는 칸 안에 넣습니다. 접는 칸은 details 태그로 열고, 그 바로 안에 summary 태그로 칸 이름을 적고, 내용을 적은 뒤 details 태그를 닫습니다. 여는 태그와 닫는 태그는 반드시 짝을 맞춥니다.
6. 운영 메모: 글 맨 끝에 담당자가 복사해서 쓰는 운영 메모를 둡니다. 운영 메모는 코드 상자 하나에 넣습니다. 코드 상자를 여는 표시와 닫는 표시를 빠짐없이 둡니다.
7. 각주 정의, 출처 목록, 내부 링크, 문의 칸 태그는 코드 상자 밖에 둡니다. 코드 상자 안에 넣으면 게시판이 그것을 글자 그대로 보여 주어 링크와 접는 칸이 작동하지 않습니다.

편집위원회 메모: 이 규정은 휴대전화로 보는 분들이 긴 글에서 필요한 곳으로 바로 가고(목차), 자주 묻는 것만 펼쳐 보고(문의 칸), 담당자는 운영 메모를 한 번에 복사할 수 있게(코드 상자) 하려는 것입니다.
