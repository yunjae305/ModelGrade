```bash

```
- `다시 평가할 판정이 없습니다.` 가 나오면 끝난 것 → 2번으로. 모델별 `실패 N턴` 이 나오면 아직 남은 것(오류가 없는 모델은 줄이 안 나옴).
- 실패 턴이 남아 있으면: 재평가 프로그램이 아직 도는지 PowerShell 로 확인 — `Get-CimInstance Win32_Process -Filter "name='python.exe'" | Where-Object { $_.CommandLine -like '*reeval_failed*' }` (07:09 에 시작한 PID 13200). 돌고 있으면 끝날 때까지 기다림(**모든 모델이 끝나야 파일에 한 번에 씀**). 돌고 있지 않으면(창을 닫아 멈춘 경우 등) **서버가 꺼진 상태에서** 한도 없이 다시:
```bash

```
- 그래도 시간 초과가 남으면 `--timeout 9000` 으로 더 늘려 다시 (사용자: "제한시간에 걸린다면 시간을 더 늘려서 평가해"). 출력 한도 미완료는 `--max-output 0`(한도 없음).
