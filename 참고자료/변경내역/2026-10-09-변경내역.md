## 상세 변경

- API 기본값은 `gpt-6.1-sol`, 추론 `high`, 제한 시간 180초, 출력 한도 12,000토큰, 검색 도구 최대 4회입니다. 모델·주소·한도는 환경변수로 변경할 수 있습니다. 공식 OpenAI Docs의 모델·Responses·검색·구조화 출력 명세를 확인했습니다.
- API는 요청당 독립 세션, `store=false`, `truncation=disabled`, 자동 재시도 없음으로 실행합니다. 인증 오류·거부·불완전 응답·잘못된 구조는 호출 오류/미판정으로 보존하며 CLI나 다른 모델로 자동 대체하지 않습니다.
- J5 참조 자료 인용은 실제 입력의 부분 문자열인지 검사합니다. 웹 근거의 URL은 실제 완료된 검색 도구 기록·제공자 인용 주석과 대조합니다. 답변의 출처 주장만으로 검색 실행을 인정하지 않습니다. 이 URL 검사는 외부 본문 인용의 정확성이나 사실 판단 자체를 독립적으로 보증하지 않습니다.
- J6는 턴과 인용문이 원문에 존재하는지 검사합니다. 유효한 인용이 없는 PASS, 대화 턴 누락·중복·잘못된 이력은 확인 필요로 남깁니다. CLI의 자동 맥락 축약 이벤트도 완료 판정으로 인정하지 않습니다.
- 확인된 다른 기준의 FAIL은 유지합니다. 확인 필요 수는 평가 진행률과 상세 결과에 별도 표시하며, 사실이 없는 답변의 J5 제외 사유도 보관합니다.
- `python -m code_eval.semantic_check`는 설정·로그인만 확인합니다. `--smoke`는 참조 모순 및 30턴 지시 변경, `--web-smoke`는 공개 Python 문서 검색을 실제 호출로 점검합니다. 고객 데이터·저장 실행은 사용하지 않습니다.
