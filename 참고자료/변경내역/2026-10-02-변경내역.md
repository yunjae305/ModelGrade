## 상세 변경

- 깨진 문자의 맥락 단위: 코드블록 내용은 바로 앞뒤 문단, 표 행은 헤더와 표 앞뒤 줄, 목록 항목은 이어지는 줄과 목록을 여는 줄, 그 밖에는 문단과 가까운 앞뒤 줄을 본다. FAIL 사유에는 "실제 출력 결과로 제시됨" 또는 "주변에 설명·예시 없음"을 적고 손상 원인은 추정하지 않는다.
- 외국 문자: 한자·히라가나·가타카나는 Unicode Scripts 범위로, 그 밖의 문자(키릴·태국·아랍·히브리·데바나가리 등)는 문자 이름으로 구분한다. 라틴·그리스·한글은 대상이 아니다(예: π). 문자 조건이 있는 질문은 2-1만 판정해 같은 문자로 두 번 FAIL 하지 않는다.
- 번호 제거 범위: `taxonomy.py` 기준 설명, 마커 목록 JSON 설명, IMPLEMENTATION_MAP·MEASUREMENT_v16·연결표, v18 HTML의 `기존 검사` 표기. 4번 기록에서 v17과 맞추려고 남긴 번호도 이번에 뺐다.
- v18 HTML은 v17을 바탕으로 1-1 설명, 깨진 문자 예시 구분 절, 외국 문자 절, 운영 탭 17곳을 고쳤다.
- 2-2를 무결성으로 옮기거나 1-2와 합치는 안은 사용자 결정으로 하지 않았다.
- 구분선 없는 파이프 줄은 화면에 표로 보이지 않으므로 계속 표로 인정하지 않는다.
- 리포트는 표시본이 있으면 표시본에도 같은 방식으로 표시한다. 웹 HTML 내보내기도 같은 리포트를 쓴다.
- 테스트 추가: 깨진 문자 맥락 9개 경우, 질문 주제, 외국 문자 6개 경우, 문자 조건 위임, "헤더 없이" 1행 표 4개 경우.
