## 설치 · 처음 설정 — 명령 몇 개로 Windows · macOS 에 깔고 모든 로그인까지 (사용자 10-26 저녁)

사용자: "진짜 스킬마냥 설치해서 사용하게 할거야 … 오픈소스 설치 … 윈도우와 mac 둘 다에서 전부 다 정상작동 … 간단한 명령어들로 전부 설치가 되고 각종 ai로그인들도 전부 되게 … env는 example 깔끔하게 수정해둬. 어떤 것들을 넣어야하는지 주석도".

- 한 줄 설치: Windows `irm https://raw.githubusercontent.com/yunjae305/ModelGrade/main/install.ps1 | iex` · macOS · Linux `curl -fsSL …/install.sh | bash` — 저장소 밖에서 불리면 `~/ModelGrade`(MODELGRADE_HOME)로 받고(git, 없으면 ZIP · tar) 그 폴더의 설치를 실행. curl | bash 는 키 입력을 터미널(/dev/tty)에서 받음.
- 설치 스크립트 두 벌(6단계): 파이썬 3.10+ · Chrome · Node.js 가 없으면 Windows 는 winget, macOS 는 Homebrew 로 설치(Linux 는 안내) → `.venv` · 패키지 → `.env` → Codex CLI · Claude CLI(npm, `MODELGRADE_SKIP_CODEX` · `MODELGRADE_SKIP_CLAUDE`) → 전역 `modelgrade` 명령(Windows 사용자 PATH 에 설치 폴더, macOS · Linux `~/.local/bin/modelgrade` 바로가기 + 셸 rc 의 PATH) → 터미널이면 `modelgrade setup`, 아니면(CI · `MODELGRADE_NONINTERACTIVE`) 점검만. PowerShell 5.1 에서 네이티브 오류 글로 멈추지 않게 종료 코드로 판단.
- `modelgrade setup`(`tools/setup_wizard.py`): ① `.env` 키를 하나씩 물음 — OPENAI_API_KEY(필수) · TYPESAFE_API_KEY · AIONA 아이디 · 비밀번호, 키 · 비밀번호는 숨겨 받고 화면 · 로그에 쓰지 않음, 다른 줄 · 주석은 그대로 ② Codex CLI(`codex login status` → `codex login`) · Claude CLI(`claude auth status` JSON → `claude auth login`) 로그인 ③ 수집용 Chrome 에 네 사이트 창 → 로그인 뒤 창마다 로그인 화면이 남았는지 확인(AIONA 는 .env 아이디가 있으면 수집기가 로그인) ④ 점검. `--keys` · `--cli` · `--web` 로 하나만. `modelgrade login` = `setup --web`.
- 어느 폴더에서나: 실행 래퍼가 `MODELGRADE_HOME` 을 넘기고 `env_value` 는 지금 폴더에 `.env` 가 없을 때 그 폴더의 `.env` 를 읽음. `modelgrade.sh` 는 바로가기로 불려도 진짜 설치 폴더를 찾고, `.venv` 가 없으면 3.10 이상인 파이썬을 골라 씀(Windows 의 python3 스토어 안내 프로그램 피함).
- macOS: 입력칸 전체 선택 `Control+A` → `ControlOrMeta+A`(Cmd+A, ChatGPT · Claude · Gemini 수집기 · FactChat).
- `.env.example` 정리: 1 필수(OPENAI_API_KEY) · 2 로그인(명령으로 하는 것 — 값 없음) · 3 권장(Jev 키 · AIONA 계정) · 4 수집 환경 · 5 심판 모델 · CLI 경로 · 6 판정 흐름 조정(FIRST_JUDGE_MODE=stances 등) · 7 다른 AI 서비스 · 질문 세트 · 8 옛 기능(지금 흐름에서 안 씀 — SEMANTIC_*), 키마다 무엇에 쓰는지 · 어디서 받는지 주석. 옛 'auto' 흐름 전용 FIRST_JUDGE_VOTES 는 뺌(코드 기본값 3 그대로).
- CI 설치 시험(Windows · macOS · Linux): Claude CLI 건너뜀 · 묻지 않음, 홈 폴더에서 전역 명령(`~/.local/bin/modelgrade setup` · `modelgrade.cmd setup`)이 설치 폴더를 찾는지.
