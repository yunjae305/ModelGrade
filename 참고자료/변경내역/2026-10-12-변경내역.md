## 배경

사용자가 제공한 `AIONA_winz_단일28_멀티10-30_질문30_id_turns.json`을 실제 화면으로 업로드하고, 답변 수집부터 평가 결과 표시까지의 시간·오류·보류·비용을 확인하며 개선하도록 요청했습니다. 10월 11일 밤에 시작해 12일 새벽에 마친 작업입니다. 자료는 30개 질문 묶음, 총 68개 Q/A입니다. 각 전체 실행에서 Gemini·Claude·GPT가 68개씩 답변을 생성하고, 업로드한 AIONA 68개까지 총 272개 답변을 평가했습니다.

답변 수집 모델은 `gemini-3.8-flash`, `claude-sonnet-5-5`, `gpt-6-luna`이며, 의미평가는 등록된 Claude API의 `claude-sonnet-5-5`, adaptive thinking, effort `medium`을 사용했습니다. CLI 평가로 대체하지 않았습니다.

### 남아 있는 보류·오류와 평가 범위

- 최종 실행은 272개 호출을 모두 처리했으며 **보류 100개 + 호출 형식 오류 1개 = 미완료 101개**입니다. 따라서 최종 점수·순위를 확정하지 않습니다. API `SUCCESS`는 응답 처리 성공이며, 근거 검증까지 완료된 품질 PASS와 다릅니다.
- J5는 PASS 29, FAIL 1, 미적용 147, `UNVERIFIED` 94입니다. J6는 PASS 138, FAIL 2, `UNVERIFIED` 12입니다. J5·J6 보류 합계 106개는 기준 단위이고, 중복 문항을 제거하면 보류 레코드 100개입니다.
- J5 보류의 근거 유형은 input 72, web 18, mixed 2, none 2입니다. Q30 대화의 input 보류가 61개입니다. 변환 범위 인용이 비어 있거나 질문에 없는 표현이고, 출처를 제출하지 않은 사례가 많습니다. 정확한 사용자 자료 인용이 확인된 Q30_T26의 AIONA/GPT는 PASS였으며, 같은 문항이라도 다른 생성 답변·근거 제출에 따라 결과가 다릅니다.
- J6 보류는 전체 FAIL인데 개별 점검과 설명은 모두 정상이라고 한 자기모순 5개(AIONA Q30_T11·T27, GPT Q30_T4, Gemini Q30_T9·T26), 점검 근거 미제출 4개(Gemini Q30_T12, Claude Q30_T5·T10·T23), 실제 인용 불일치 3개(Claude Q29_T7, Q30_T3·T13)입니다. 프로그램이 임의로 PASS로 올리지 않습니다.

## 상세 변경

- 직접 입력은 한 쌍의 `cases`로 기존 `/api/comparison/runs`를 호출합니다. 공백·줄바꿈을 다듬지 않고 보존합니다. 빈 질문·답변은 UI에서 시작 불가, 서버도 유료 호출 전에 검증합니다. 입력 전환 시 파일과 직접 입력 초안을 각각 보존합니다.
- 비교 API에는 질문만 보냅니다. 세 모델의 응답 수집이 끝난 뒤 저장된 AIONA 답변과 함께 평가합니다. 기존 블라인드 식별자·동시 수집·의미 평가 경로를 유지합니다.
- `POST /api/comparison/model-versions`의 register/activate는 평가를 호출하지 않습니다. 버전 카탈로그와 등록 시각·메모·현재 버전을 잠금 안에서 임시 파일 후 교체 방식으로 저장합니다. 중복 등록은 원본 설정을 변경하지 않고 거부합니다.
- `GET /api/comparison/version-history`에 `releases`, `current_release`를 추가합니다. 새 실행의 `expected_model_version`이 현재 버전과 다르면 호출 전에 거부합니다. 이미 저장된 실행의 버전은 현재 사용 버전을 변경해도 유지합니다.
- AIONA v1과 기준 실행 `65d50fe3b23d` 1개를 유지합니다. 카탈로그에 v1을 등록하고 기존 설정은 `backups/run-history/20261012-105745-v1/lifecycle-before.json`에 보관했습니다.
- 실행에 `input_mode`와 `aiona_specialized: false`를 기록합니다. 비교 평가에서는 설정의 enabled를 false로 전달하여 특화 검사 자체를 건너뜁니다. 일반 평가 엔진 기본 동작과 별도 상세 도구는 그대로 유지하며, 과거 판정은 수정하지 않습니다.

## 상세 변경

- `GET /api/comparison/runs/{id}/version-template`은 기준의 질문·참조 자료·문항 ID·대화 ID·턴 번호를 보존하고 답변은 빈 값으로 내보냅니다. 이전 답변이나 모델 식별 정보는 포함하지 않습니다.
