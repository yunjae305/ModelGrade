# 공개 세트 검토 — IFEval-Ko · KoMT-Bench 를 우리 질문생성 프롬프트 기준으로 (2026-10-25, 할일 7번)

사용자 지시: "네가 보고 우리가 세운 질문생성 프롬프트 기준에 맞는 질문이 있으면 채택하고 없으면 현재 질문생성 프롬프트만 개선시켜." 수집은 하지 않음.

## 결론
- **채택 없음.** 변동 기준 k 6~10 을 만족하는 공개 질문은 IFEval-Ko 3개뿐이고 그마저 자료 없는 질문에 J5 가 붙어 k 가 부풀려진 것. KoMT-Bench 는 0개.
- **질문생성 프롬프트 v3.6** 으로 개선: 변별이 없던 기준을 겨냥한 함정(1장) · 검증 가능한 지시 종류 표(3-1장) · 분야 폭(작성 규칙 8) · 번역투 금지.

## 방법
1. 원본: `data/question_sets/public_sources/ifeval_ko.json`(342, allganize/IFEval-Ko, Apache-2.0) · `komt_question_ko.jsonl`(80개 2턴, LGAI-EXAONE/KoMT-Bench, LGPL-3.0). git 이력(2ae0027 직전 `examples/fixed_sets/sources/`)에서 복구.
2. 우리 questions.json 형식(id · type '단일 질문' · turns[{turn:1, question}])으로 변환. KoMT 는 1턴만(2턴 대화는 프롬프트의 '2턴 금지' 규칙과 충돌).
3. `python -X utf8 tools/check_question_set.py <파일> --pipeline items --min-applicable 10 --json` 으로 질문마다 적용 기준(checks + items)을 세고, `webapp.question_generation.k_var_units()`(54개)와의 교집합 크기를 k 로 — 질문생성 프롬프트 2장의 공식 계산과 같은 정의. 모델 호출 없음.
4. 같은 잣대로 우리 78 세트 단일 57개(일반 35 · 첨부 12 · 롱컨텍스트 10)를 세면 k 6:13 · 7:19 · 8:14 · 9:10 · 10:1 — 모두 범위 안(잣대 확인).

## 인식기가 IFEval 지시 종류를 얼마나 알아보나 (질문당 CODE 변동 검사 평균)

| 잘 알아봄 (1.0 이상) | 거의 못 알아봄 (0.5 미만) |
|---|---|
| JSON 형식 2.36 · 금지어 1.14 · 섹션(multiple_sections) 1.09 · 단어 수 1.08 · 불릿 수 1.08 · 문단 수 1.05 · 필수어 1.05 · 문장 수 1.0 | <<제목>> 0.44 · 끝 문구 0.47 · 두 답(******) 0.37 · 빈도 0.36 · 쉼표 금지 0.31 · 큰따옴표 감싸기 0.25 · 자리표시자 0.2 · 요청 반복 0.19 · 추신 0.16 · 응답 언어 0.12 · 정해진 답 0.1 |

→ 프롬프트 3-1장 표: 잘 알아보는 종류는 우리 인식 문구로 쓰고, 못 알아보는 종류 중 한국어에 맞는 것(추신 · 요청 반복 · 두 답 · 큰따옴표 · 쉼표 금지 · 자리표시자)은 심판(J2-3.a)이 보는 지시로 질문당 1개까지, 응답 언어 · 영어 빈도 · 대문자는 안 씀. 새 CODE 검사를 만들지는 않음(후속 후보).

## 우리 세트가 약한 곳 (10-25 결과, 78 질문 × 네 모델에서 FAIL 0)
- LLM: J2-1.a · J2-1.b(눈높이, 적용 10 질문) · J2-2.a(말투, 26) · J2-4.a(비유, 15) · J3-2.a(전제, 16) · J8-1.a · J8-2.a · J8-3.a(첨부, 12).
- CODE: 2-1.char_count · 2-2.table · 2-2.heading · 2-2.json_structure · 1-2.json_syntax · 3-3.transform · 3-3.unique_values 등 15개.
- 단일 일반 질문은 자료 처리(JSON) · 파이썬 함수 · 안내문 · 사과문에 몰림 → KoMT 8분야 중 역할극 · 추론 · 수학 · 과학기술 · 인문 설명이 적음. 프롬프트 1장 함정 규칙과 작성 규칙 8 에 반영.

## 하지 않은 것
- 공개 질문 수집 · 판정(변별 비교)은 하지 않음 — 채택한 질문이 없어 비교할 대상이 없음. 원하면 k 5 이상 7개로 시험 수집을 할 수 있으나 우리 규칙 밖 질문이라 권하지 않음.
- 새 CODE 검사(빈도 · 추신 · 큰따옴표 감싸기 등)는 만들지 않음 — 필요하면 기준 v2 문서 → 코드 순으로.
