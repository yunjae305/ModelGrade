평가는 하지 않은 수집 결과입니다. 질문과 세 모델의 답변 원문을 그대로 담았습니다.

## 어떻게 만들었나

- **질문**: 질문 생성기 question-gen-v1.4 로 질문 수를 정하지 않고 `per_target=10` — 세부 기준마다 적용 질문이 10개가 될 때까지 GPT(`gpt-6-luna`)가
  모자란 기준을 노려 질문을 추가했다. 10턴 대화 10개(답이 턴마다 길게 나오도록 설계, 질문 문장에 분량 요구는 없음)와 긴 문서 하나를 함께 쓰는 J7 질문 10개를
  전용 단계에서 먼저 만들었다. 의미 점검 항목은 세부 기준·판정 근거·펼침·FAIL 예까지 보고 만들었다.
- **덮은 정도**: 세부 기준 80개 중 79개가 10번 이상 적용(글자 수 조건만 7번). 이 세트 안에서 고르면 항목마다 1번 18개, 5번 107개, 10번 261개 질문이면 된다(탐욕 근사).
  답변을 받아야 정해지는 검사 7개와 J5-3.a 는 질문만으로 셀 수 없어 목표에서 뺐다.
- **생성 경고**: 이미지 첨부 2건(Q200, Q266)은 'png' 종류로 와서 파일이 만들어지지 않아 첨부 없이 남았다.
- **수집**: 웹의 '질문 세트 실행'과 같은 경로. GPT·Gemini 는 API + 웹 검색 도구(api-tools-v4), AIONA 는 winz.aiona.kr 웹 자동화(aiona-web-v1, 기본 '자동 추천').
  추론 강도는 GPT·Gemini 모두 medium, 최대 출력 8,000 토큰. Claude 는 계정 크레딧 부족으로 수집하지 않았다.
- **실패한 턴만 다시 받기**: 성공한 턴은 그대로 두고 실패한 턴만 다시 요청했다. 대화 중간 턴은 앞 턴의 성공 답변을 이력으로(AIONA 는 앞 턴이 성공한 같은 채팅을 열어)
  이어서 물었다. `answers.json` 의 `retried: true` 가 다시 받은 턴이다.
