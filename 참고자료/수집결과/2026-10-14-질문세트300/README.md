## 어떻게 만들었나

- **질문**: 질문 생성기 question-gen-v1.2 로 질문 수 300개를 지정해 GPT(`gpt-6-luna`)가 만들었다. v1.2 는 CODE 검사 28개·의미 점검 항목 단위로 덮었고,
  세부 조건 단위(v1.4)나 10턴 대화·긴 문서 질문 수 지정(v1.3) 전의 생성기다 — 그래서 세부 조건 3개(시작 문구·끝 문구·표 열 수)는 적용되지 않았고
  J6 10턴 대화는 1개, J7 긴 문서 질문은 1개뿐이다 (`tools/min_question_count.py` 로 확인).
- **수집**: 웹의 '질문 세트 실행'과 같은 경로. GPT·Gemini 는 API + 웹 검색 도구(api-tools-v4), AIONA 는 winz.aiona.kr 웹 자동화(aiona-web-v1, 기본 '자동 추천').
  추론 강도는 GPT·Gemini 모두 medium, 최대 출력 8,000 토큰. Claude 는 계정 크레딧 부족으로 수집하지 않았다.
- **실패한 턴만 다시 받기**: 처음 수집에서 실패한 턴만 다시 요청하고 성공한 턴은 그대로 두었다. 대화 중간 턴은 앞 턴의 성공 답변을 이력으로(AIONA 는
  앞 턴이 성공한 같은 채팅을 열어) 이어서 물었다. `answers.json` 의 `retried: true` 가 다시 받은 턴이다.
- **알려진 미완료**: Gemini Q32 대화 9턴은 추론 토큰이 출력 한도에 포함돼 두 번 모두 MAX_TOKENS 로 잘렸고(INCOMPLETE), 그래서 10턴은 받지 못했다.
