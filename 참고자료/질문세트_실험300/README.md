# k 범위 실험 질문 300개를 AIONA 에 직접 넣기 (세트 qs-e2e58d7835df)

목적: k 범위 실험(k 1~16, 2026-10-18)에 AIONA 답을 더해 03장 k 별 수치 표·차트를 네 모델로 만든다. GPT·Claude·Gemini 답은 이미 있고(실행 e4ce7a342251 등), **AIONA 300개만** 받으면 된다.

## 파일

| 파일 | 내용 |
|---|---|
| `questions.md` | 질문 300개 원문 (Q1~Q300, k 값·첨부 표시) — 읽기용 |

| `answers.csv` | **답을 적어 돌려줄 파일** — id 는 채워져 있고 answer 칸만 채우면 됨 (chat_url·note 는 선택) |
| `questions.json` | 원본(프로그램용) |

## 보내는 법 — "프롬프트"는 질문 원문 그대로입니다

- AIONA 에는 **시스템 프롬프트나 지시문을 따로 넣지 않습니다.** 질문 원문(```text``` 안의 글)을 한 글자도 바꾸지 않고 그대로 보냅니다. 앞뒤에 "다음 질문에 답해줘" 같은 말도 붙이지 않습니다.
- 질문마다 **새 채팅**을 엽니다 (앞 질문의 맥락이 섞이지 않게). 모두 단일 턴이라 한 채팅에 질문 하나입니다.
- 첨부가 있는 질문(Q256~Q267, `attachments` 칸)은 `첨부/` 의 파일을 질문과 함께 올립니다.
- 개인정보 확인 안내("마스킹하거나 그대로 전송할 수 있습니다")가 뜨면 **마스킹 후 전송**을 누릅니다.
- 답은 답변 **맨 아래 도구 줄의 📋 복사 버튼**으로 전체를 복사합니다(코드블록 안의 복사 버튼은 코드만 복사됨). 복사한 원문을 `answers.csv` 의 answer 칸에 그대로 붙여 넣습니다(줄바꿈 포함, 고치지 않음).
- "처리 중 오류" 화면이 나오면 한 번 다시 보내고, 그래도 안 되면 answer 를 비우고 note 에 `오류 화면` 이라고 적습니다.
- 가능하면 chat_url 에 그 채팅의 주소를 적어 두면 나중에 다시 복사할 수 있습니다.

## 돌려주는 법

`answers.csv` 를 채워 이 폴더에 그대로 두고 push 하거나 보내 주세요. 받으면 (평가 PC 에서) ① 답을 AIONA 실행으로 올리고 ② CODE + Jev·Luna 병행 평가 ③ k 별 "모두 PASS / 갈림 / 모두 FAIL" 을 네 모델로 다시 세어 03장 표·차트를 바꿉니다. 평가 비용은 Luna 약 $5~8 추정.
