차별점 — 기준별 판정과 고치는 루프

기준별(블록별) 판정이라 어디가 틀렸는지 바로 보이고, 결과 · 보류 · 사람 판단을 쌓아 판정 프롬프트 · 질문 생성을 고치는 루프가 돕니다.

  1. 기준 72개를 블록별로 판정한다 — 점수 하나가 아니라 어느 기준을 어겼는지.
  2. 질문마다 목표 기준을 미리 정해 두고, 어느 답이든 같은 항목을 본다 — 답에 따라 항목이 사라지지 않음.
  3. 심판 셋(1차 3표 + Codex 확정)과 안전장치(인용 대조 · 사유 점검)로 거짓 FAIL 을 줄이고, 갈리면 보류 → 사람.
  4. 결과 · 보류 · 사람 판단을 재료로 기준 문서 → 프롬프트 → 코드 순으로 고치는 루프 — harness2 방식, 코드는 안 가져옴.
  5. 같은 질문 · 같은 기준 · 고정 프롬프트라 업데이트마다 전후 비교가 된다.

고치는 루프 — harness2 방식(체크리스트 5장)

  1. 모으기FAIL · 보류 + 같은 수의 통과 칸 + 사람 표시(표시용 표)
  2. 원인 나누기답이 틀림 / 프롬프트 / 기준 / 질문 / 수집
  3. 고칠 안AI 가 2~3개 제안 — 어디를 고칠지 포함, 질문 글은 못 바꿈
  4. 시험같은 칸을 고치기 전 · 후로 다시 판정 → 사람 표시 대비 정답률 · 뒤집힘
  5. 채택정답률↑ · 뒤집힘↓ · 다른 기준 안 나빠질 때만. 기준 변경은 사람 승인, 교훈은 기준 문서에
