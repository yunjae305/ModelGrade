부록 C. harness2 는 어떻게 쓰나 — 코드는 안 가져오고 방식만

구현됨(10-25 밤) — tools/refine_loop.py: 모으기(FAIL · 보류 + 같은 수의 통과 칸, 표시용 표) → 제안(Claude CLI, 많아야 3안, 질문 글은 못 바꿈) → 같은 칸 전후 재판정(안을 임시 프롬프트 · 항목 정의 · 확인 목록에 넣고 judge_v4) → 채택 판단(사람 표시 정답률 · 뒤집힘 · 다른 항목 변화 5% 상한) → 교훈(기준 v2 12절). 사람 표시가 없으면 채택하지 않고 "사람 확인 필요"까지만. 연기 시험: 통과 칸만 주면 제안자가 KEEP_BASE 를 냄.
