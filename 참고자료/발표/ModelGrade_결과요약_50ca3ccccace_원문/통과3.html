def unique_stops(stops):

    """경유지 목록에서 중복을 제거하고 첫 등장 순서를 유지한 새 리스트를 반환합니다."""

    seen = set()          # 이미 나온 항목을 기록하는 용도로만 사용합니다.

    result = []

    for stop in stops:    # 순서는 입력 목록의 순회 순서를 따릅니다.

        if stop not in seen:

            seen.add(stop)

            result.append(stop)

    return result





# 사용 예

## 먼저 용어를 도서관에 대응시키면



| 코드 세계 | 도서관 비유 |

|---|---|

| 서버의 원본 데이터 | 도서관 사서가 관리하는 **공식 대출 장부** |

| 캐시 | 안내 데스크 옆에 붙여 둔 **복사본 대출 현황표** |

| 화면(브라우저, 앱) | 이용자가 **눈으로 보는 것** |

| 서버의 값을 수정함 | 사서가 공식 장부에서 "대출 중"을 "반납 완료"로 고침 |

| 캐시를 비움 | 붙여 둔 현황표를 떼어 내고 **장부를 보고 새로 베껴 쓰기** |



## 관찰하신 순서대로 풀어 보면



**1단계: 처음에 값을 가져올 때**

이용자가 어떤 책의 상태를 물으면, 매번 사서에게 달려가 장부를 펼치는 것은 번거롭습니다. 그래서 한 번 확인한 내용을 현황표에 적어 안내 데스크 옆에 붙여 둡니다. 코드에서는 서버에서 받은 값을 캐시에 저장해 두는 일에 해당합니다.



**2단계: 서버의 값을 수정했을 때**

사서가 공식 장부를 고쳤습니다. 이 시점에서 원본은 이미 새 값입니다. 다만 안내 데스크 옆 현황표는 **누가 고쳐 주기 전까지는 그대로**입니다. 현황표는 장부가 바뀐 사실을 스스로 알지 못하기 때문입니다.



**3단계: 화면에 이전 값이 남아 있을 때**

이용자는 가까이 붙어 있는 현황표를 먼저 봅니다. 그래서 장부는 새 값인데 눈에 보이는 것은 옛 값인 상태가 됩니다. 이것이 말씀하신 첫 번째 관찰입니다.



**4단계: 캐시를 비웠을 때**

현황표를 떼어 내면 이용자는 어쩔 수 없이 장부를 다시 확인하게 되고, 그 결과가 새 현황표에 적힙니다. 이때 비로소 새 값이 보입니다. 이것이 두 번째 관찰입니다.



## 핵심 원리



캐시는 **빠르게 보여 주기 위한 복사본**이고, 원본은 **기준이 되는 진짜 기록**입니다. 복사본은 만들어진 시점의 내용을 담고 있으므로, 원본이 바뀐 뒤에도 복사본을 갱신하는 일이 따로 일어나지 않으면 두 값이 한동안 어긋납니다. 그래서 캐시를 비운 뒤에 새 값이 보였다는 사실은 **원본에는 새 값이 이미 들어 있었다**는 점과 잘 맞아떨어집니다.



## 다만 단정하지는 않겠습니다



지금 관찰만으로는 "원본 저장이 성공했다"고 확정하기도, "실패했다"고 확정하기도 어렵습니다. 다만 캐시를 비운 뒤 새 값이 보였다는 점은 **원본 저장 실패보다는 오래된 복사본이 남아 있었다는 설명에 더 가깝다**는 정도로 읽을 수 있습니다. 비유를 이어 가면, 장부를 고쳤는지 확인하려면 현황표가 아니라 **장부를 직접 펼쳐 보는 것**이 가장 확실합니다. 코드에서는 서버 응답이나 데이터베이스의 값을 직접 조회해 보는 방법이 이에 해당합니다.



## 한 가지 더 알아 두시면 좋은 점



도서관에는 현황표가 한 군데만 있지 않을 수 있습니다. 코드에서도 브라우저 캐시, 서버 앞단의 캐시(CDN 등), 애플리케이션 내부의 메모리 캐시처럼 복사본이 여러 층에 있을 수 있습니다. 어느 층의 복사본이 옛 값을 들고 있었는지는 이 관찰만으로는 알 수 없으므로, 필요하시면 그다음 단계로 어느 캐시였는지 좁혀 가시면 됩니다.

# 생활강좌 신청 안내: 처음 신청하는 성인

처음 신청하는 성인은 **수강 신청서**를 제출하면 됩니다. 주민 확인서와 참여 동의서는 모든 성인에게 필요한 서류가 아니며, 수강료는 안내문에 금액이 없어 **미기재**입니다.

## 제출 서류와 방법

| 서류 | 필요한 대상 | 제출 방법 | 제출 부서·장소 | 안내 사항 |
|---|---|---|---|---|
| 수강 신청서 | 모든 신청자 | 현장 또는 온라인 제출 | 접수창구 | 중복 제출은 필요하지 않음 |
| 주민 확인서 | 감면 신청자 | 현장에서 원본 확인 | 교육지원실 | 확인 후 원본 반환 |
| 참여 동의서 | 미성년 신청자 | 현장 제출 | 학습지원실 | 주민 확인서와 별도 서류 |

## 성인 신청자가 확인할 점

감면을 신청하지 않는 성인은 **주민 확인서나 참여 동의서를 일괄 제출할 필요가 없습니다**. 감면을 신청한다면 주민 확인서를 현장에 가져가 교육지원실에서 원본 확인을 받으면 됩니다.

📌 교육지원실과 학습지원실은 서로 다른 제출 부서이므로 서류별 제출처를 확인해 주세요. **수강료는 별도 공지**라고만 안내되어 있어 금액은 미기재입니다.첨부 문서의 현재 확인 범위는 2026년 9월 25일 반영 내용입니다.
