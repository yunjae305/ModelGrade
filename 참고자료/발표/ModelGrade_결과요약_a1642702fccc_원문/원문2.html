파이썬에서 `if x:`와 같이 단순 조건문으로 필터링을 하면, 숫자 `0`이나 `False`도 거짓(Falsy)으로 처리되어 함께 사라져 버립니다. 하지만 `if x is not None`을 명시해주면 `0`이나 `False`는 그대로 두고 오직 **`None` 데이터만 정확하게 제외**합니다.
2. **원본 목록이 유지되는 이유**
1`[x for x in ...]` 형태의 리스트 컴프리헨션(List Comprehension)을 사용하면, 기존 입력 목록을 변경하는 대신 조건에 맞는 요소들만 모아 **새로운 리스트**를 새로 만들어 반환합니다.

---

### 파이썬 코드 및 사용 예시

```python
def remove_none_values(measurements):
    """
    측정값 목록에서 None만 제거한 새 목록을 반환합니다.
    숫자 0과 False는 보존되며 원본 목록은 수정되지 않습니다.
    """
    return [x for x in measurements if x is not None]


# --- 사용 예시 ---
# 1. 원본 측정값 목록 준비 (None, 0, False, 일반 숫자가 섞여 있음)
original_measurements = [23.5, None, 0, False, 18.2, None, 0.0]

# 2. 함수 실행하여 None만 제거된 새 목록 생성
cleaned_measurements = remove_none_values(original_measurements)

# 3. 결과 출력
print("원본 목록:", original_measurements)
print("정리된 목록:", cleaned_measurements)

# 4. 원본 목록이 수정되지 않았는지 확인 (True 출력)
print("원본 목록이 유지되었나요?", original_measurements is not cleaned_measurements)

```
