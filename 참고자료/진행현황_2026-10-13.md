## 3. 앞으로 할 것 (순서)

1. **실시간 items·Batch 실측(키 필요)** — 저장 실행 1개를 `SEMANTIC_PIPELINE=items` 로 재평가해 legacy 와 기준별 차이표 작성, `SEMANTIC_DISPATCH=batch` 로 소규모 실제 Batches 호출 1회(API 형식·만료 재전송 확인). 재확인의 J5 서버 검증이 부분집합 항목만 보는 한계(본 평가의 J3 제외 규칙 미적용)도 여기서 실측. 이 환경에는 키·로컬 데이터가 없어 보류.
2. **4단계 기준 정의 데이터·미판정 표시** — `code_eval/settings/code_check_conditions.json`(검사 28·세부 조건 194), `criteria_detail.py`, taxonomy/registry 확장, 평가 기준 화면·code-eval 화면·보고서에 검사→세부 조건, 질문 상세에 '판정하지 않은 조건'·'검사 실행 오류'. 의미 25/39 정의는 `semantic_items.describe()` 한 곳만 쓴다(registry v2·changelog 반영 완료, 화면은 미반영).
3. **4단계 외부 수집 답변(웹·에이전트)** — `webapp/external_answers.py`(모델 1개당 JSON 1개, 질문 세트 지문 검증), `/api/comparison/external-answers`, providers 일반화(`_display_name`), 화면 업로드·질문 세트 내려받기, 블라인드 N 모델.
4. **4단계 subs 화면·보고서** — 모델 카드 통과율·충족률·질문 통과율, 기준 비교표 세부 행, 보고서(`report_html`)에 세부 기준·항목 (질문 상세 블록은 완료), 이력 추이 화면(시간축 통과율·기준/평가 모델/수집 모델 변경 시점 — 데이터는 3d 에서 준비).
5. **4단계 검증 도구** — `tests/verification_common.py`, `analyze_sample_size.py`(질문 수 50~300·부트스트랩 CI·순위 안정), `analyze_human_agreement.py export|score`(Cohen κ), `analyze_reproducibility.py`, `analyze_pipeline_diff.py`(legacy vs items·부호검정), `export_j5_sample.py`.
6. **대화 세트 2단계** — AIONA 답변 수집(사람, 약 231턴) 뒤 `data/code_eval/` 에 저장, expect 재검토, 기본 세트 병합 여부 결정.
7. **문서 마무리** — 변경내역, SERVICE_UI 항목별 평가·Batch·검증 도구·외부 답변 절, README 설정 안내, MEASUREMENT §21~§23.

## 4. 정할 것 (열린 질문)

- J2-5.b(글이 목적을 수행하는가)는 설계 표에 예시가 없어 구현에서 한 쌍을 새로 썼다 — 확인 필요.
- J3-2·J3-5·J5-1·J5-2.a 의 적용 규칙 단어 목록은 설계 예시 질문 16개로만 고정했다. '뜻·의미' 규칙이 번역 질문도 J5-1 로 넣는다. 사람 판정 일치율(30문항 × 4모델) 뒤 보정.
- J5 참(TRUE) 판정도 관측된 출처 URL 을 요구한다(기억만으로 판정 금지). 검색이 꺼진 설정에서는 J5-1.a 를 보내지 않는다.
- 코드 규칙이 적용한 항목에 모델이 NOT_APPLICABLE 로 답하면 재확인 뒤 확인 불가 NO 로 둔다(검토 ④). 적용 규칙의 거짓 양성(예: '각각' 이 추가 요구가 아닌 경우)이 FAIL 로 이어질 수 있어 사람 판정 일치율에서 규칙을 보정한다.
- J6-3.b 적용 시점: 롱 컨텍스트 세트 초안은 "같은 결과물 2회 이상 편집 뒤"로 통일했으나 J6-2/J6-4 초안은 2번째 편집부터, J6-3 초안은 3번째부터 적용 — 사람 검토 때 한쪽으로 맞춘다.
- G-2(줄 수·문장 수 범위 정의)는 공식 정의 변경 승인 대상이라 미결. G-3(이전 턴 형식 지시의 코드 승계)은 채택했으나 구현 단계 미정.
- 외부 답변이 있어도 API 3개 수집을 필수로 둘지, 외부만으로도 실행을 허용할지.
- 정밀 모드는 보류.
