질문
따뜻한 방에 차가운 물병을 꺼내 놓았더니 병 겉면에 물방울이 생겼습니다. 초등학생에게 그 원리를 비유를 들어 설명하고 비유 속 요소의 대응도 알려 주세요. 먼저 병이 들어왔고 그다음 겉면에 물방울이 생겼다는 순서를 반영해 주세요.
답변
**비유: 따뜻한 방 = 수증기 친구들이 가득한 놀이공원, 차가운 물병 = 얼음 미끄럼틀**



따뜻한 방의 공기 속에는 눈에 보이지 않는 **수증기**가 둥둥 떠다니고 있어요. 수증기는 물이 아주 작은 알갱이가 되어 공기 중에서 신나게 뛰어다니는 상태예요. 이걸 "놀이공원에서 정신없이 뛰어다니는 아이들"이라고 생각해 보세요.



**1단계: 차가운 병이 들어와요.**

냉장고에서 꺼낸 물병이 방 안에 놓였어요. 놀이공원 한가운데에 얼음으로 된 차가운 미끄럼틀이 놓인 거예요.



**2단계: 겉면에 물방울이 생겨요.**

뛰어다니던 수증기 친구들이 차가운 병 표면에 부딪히면 몸이 차가워져서 더 이상 빨리 뛰지 못해요. 그러면 그 자리에 달라붙어 서로 뭉치게 되고, 그 뭉친 것이 눈에 보이는 **물방울**이 되는 거예요. 아이들이 미끄럼틀 앞에서 줄을 서서 옹기종기 모여 있는 모습과 비슷해요.



**비유 속 요소 대응표**



| 비유 | 실제 |

|---|---|

| 놀이공원 | 따뜻한 방 |

| 뛰어다니는 아이들 | 공기 중의 수증기 |

| 얼음 미끄럼틀 | 차가운 물병 |

| 미끄럼틀 앞에서 멈춰서 모여 줄 서기 | 수증기가 차가워져서 물로 변하는 것(응결) |

| 줄 서 있는 아이들 무리 | 병 겉면의 물방울 |



**꼭 기억할 점:** 물방울은 병 안에서 새어 나온 물이 아니라, 방 안 공기 속에 원래 있던 수증기가 차가운 병에 닿아 물로 변한 거예요. 이런 현상을 **응결**이라고 해요.

| 서류 | 필요한 대상 | 제출 방법 | 제출 부서·장소 | 안내 사항 |

답변
`None`만 걸러내고 숫자 `0`과 `False`는 보존하며, 원본 목록은 그대로 두는 함수예요.

## 함수와 사용 예

```python
def remove_none(values):
    return [value for value in values if value is not None]

measurements = [12, None, 0, False, 7, None]
filtered = remove_none(measurements)

print(filtered)       # [12, 0, False, 7]
print(measurements)   # [12, None, 0, False, 7, None]
```

## 동작 원리

- `value is not None`은 값이 `None`인지 **정확히 확인**합니다. 그래서 `0`이나 `False`처럼 거짓으로 취급되는 값도 삭제하지 않아요.
- 대괄호 안의 조건에 맞는 값만 모아 **새 목록**을 만듭니다. 따라서 함수에 전달한 `measurements`는 수정되지 않습니다.
- `filtered`에는 `None`이 빠진 결과가 저장되고, 원본 목록은 그대로 출력됩니다.
