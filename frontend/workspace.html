AIONA 모델 평가 워크스페이스

AIONA 질문·답변 파일을 올리면 연결된 AI가 같은 질문에 자동으로 답변합니다. 답변을 비교한 뒤 같은 기준으로 평가하세요.

평가자 설정 확인 중
AIONA 버전 평가

등록한 AIONA 답변을 현재 평가 기준으로 평가하고 새 실행으로 보존합니다. 평가자 호출이 발생합니다.

00

질문 세트 만들기

GPT가 우리 세부 기준(CODE 검사 · 의미 평가 항목)을 모두 평가할 수 있는 질문을 가장 적은 개수로 만들고, 첨부파일(이미지·TXT·DOCX·PDF)과 긴 자료도 함께 만듭니다.

어떤 파일을 올릴 수 있나요?

JSON·JSONL의 question/answer, 질문/답변, Q/A 필드와 회차별 JSON 묶음을 읽습니다. MD·TXT는 각 질문과 답변 앞에 질문:/답변:, Q:/A: 또는 User:/Assistant: 표시를 사용하세요.

# 단일턴
Q: 독립 질문 원문
A: AIONA 답변 원문

# 1회차
Q: 대화의 첫 질문
A: 첫 답변
Q: 이어지는 질문
A: 이어지는 답변

회차 제목이 있으면 같은 회차 안에서 대화를 이어갑니다. 회차 표시가 없으면 단일턴으로 분류합니다. 멀티턴(2턴 이상) 대화는 턴 수와 상관없이 독립 질문 1개로 셉니다. 구분 표시가 없는 글은 질문과 답변을 임의로 추측하지 않습니다.

    실행 설정

    요청당 최대 출력 토큰과 자동 수집 호출·비용 한도는 관리 설정에서 정합니다. 대화 ID와 턴이 있으면 각 모델 자신의 이전 응답을 이어서 사용합니다. 추가 시스템 프롬프트는 보내지 않습니다.

    +고급 · 기타 응답 파일 가져오기다른 곳에서 받은 API·웹·에이전트·외부 플랫폼 답변 파일을 같은 기준으로 평가합니다.
    여러 파일을 함께 고르면 같은 질문끼리 묶어 비교합니다. 자동 화면 수집은 하지 않습니다.
    시스템 정보 직접 입력 · 파일에 모델 정보가 없을 때
    파일을 고르면 변환 결과를 먼저 확인합니다미리 확인은 모델·평가자를 호출하지 않습니다.

    관리 설정

    모델 연결 · 자동 수집 설정

    API 키와 정확한 모델 ID를 연결하고, 업로드 직후 자동으로 답변을 받을 제공자와 호출·비용 한도를 정합니다.

    키 값은 화면·결과에 공개하지 않음

    자동 수집 허용 · 한도

    여기서 허용한 제공자에만, 한도 안에서 업로드 직후 자동으로 요청합니다. 실제 과금이 발생할 수 있습니다.

    오늘 사용량 확인 중
    제공자연결업로드 시 자동 수집입력 단가USD / 100만 토큰출력 단가USD / 100만 토큰

    요청 1회의 비용 상한 = (질문·같은 대화 앞 턴의 UTF-8 바이트 수 + 앞 턴 답변마다 최대 출력 토큰) × 입력 단가 + 최대 출력 토큰 × 출력 단가. 제공자 하나의 전체 계획이 남은 작업당·일일 한도 안에 들 때만 그 제공자를 시작하고, 응답에 사용량이 있으면 실제 토큰으로 정산합니다. 네 한도와 단가를 모두 정해야 자동 수집이 시작됩니다.

    응답 수집을 시작할 때 모델 제공자에 요청합니다. API 키는 브라우저 저장소나 결과 JSON에 포함되지 않습니다. 화면에서 등록·변경·해제한 설정은 현재 서버 세션에 적용됩니다. .env에 저장한 키와 모델은 서버를 다시 시작할 때 읽으므로, 영구 해제하려면 해당 파일에서도 제거하세요.
